Overview of: ai04 Images Media and Tables
Course: Web Design AI track

What this lesson is about:
This lesson adds images, audio, and tables to your music site, in two parts. In the first part (ai04), you direct Claude to create ai04_imagesMediaTables, copy your three pages and bio.txt forward, add a Media nav link, and build media.html with captioned images using figure and figcaption, alt text you write yourself, a decorative divider image with empty alt text, an audio player with controls for one of your tracks, and a track table with a caption and th header cells with scope column. In the second part (ai04b), you build a release page, release.html, in a separate folder called ai04b_releasePage, with cover art whose alt text and caption say different things, an MP3 preview kept in your own audio folder with fallback content inside the audio element, a track table ending in a Total running time row that uses colspan, and links to and from your music page. Along the way you learn why a music service link cannot act as an audio player. You check everything by ear with the G, T, Tab, K, and Control plus Alt plus Right Arrow keys. It matches html04 Images Media and Tables in the HTML CSS JavaScript track.

Documents in this folder, in suggested order:
1. ai04 Lesson summary.txt — build the media page with images, alt text, audio, and a track table.
2. ai04 Questions summary.txt — the topics the graded ai04 question sheet checks (questions left out; they are homework).
3. ai04b Lesson summary.txt — build a release page with cover art, an audio preview with fallback content, and a table with a total running time row.
4. ai04b Questions summary.txt — the topics the graded ai04b question sheet checks (questions left out; they are homework).

Other files in the original lesson:
The source lesson folder has no images or media files; it contains only the four Markdown documents above. The images, MP3 tracks, and preview audio are files each student supplies in their own repository.
