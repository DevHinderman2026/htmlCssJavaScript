Overview of: ai04 Images Media and Tables
Course: Web Design AI track (archived version)

What this lesson is about:
This archived unit adds a media page to your site by direction. You write your own alt text for four images, give a decorative image empty alt so screen readers skip it, embed audio and video with the controls attribute, use figure and figcaption, and build a data table with a caption and th header cells using scope. You also learn when to use JPG, PNG, and SVG. The twist is a deliberately lazy copy of the table with no headers or caption, so you can hear why proper table markup matters. The audit checks each image's alt text, the table cell by cell, the lazy table, the media controls, and whether alt text and captions repeat. The matching lesson in the HTML CSS JavaScript track is html04 Images Media and Tables.

Documents in this folder, in suggested order:
1. ai04 BuildBrief summary.txt — the media page requirements, must-say list, lazy-table twist, and files to commit.
2. ai04 AudioLab summary.txt — the five-step media audit, including the correct-versus-lazy table comparison.
3. ai04 ConceptCheck summary.txt — the topics the ai04 ConceptCheck sheet checks (questions left out; they are homework).

Other files in the original lesson:
None. The source folder contains only these three markdown files; it has no images or media files.
