Overview of: ai08 HTML Forms
Course: Web Design AI track (archived version)

What this lesson is about:
This archived unit, which the brief calls the richest in the track, covers accessible HTML forms built by direction. You have Claude build a registration form with three fieldsets and legends; text, email, radio, checkbox, select, and textarea controls; every input connected to a label through matching for and id attributes; required fields and one pattern-checked field; a descriptive submit button; and visible focus styles. You learn form, action, GET versus POST, and why tabindex should almost never be set. The audio lab uses forms mode to compare your real form with a deliberately lazy one that relies on placeholders, and you write findings in a three-part format (what announced wrong, what markup is missing, what the fix is). You also hear how the browser blocks an invalid submit and moves focus to the problem field. The matching lesson in the HTML CSS JavaScript track is html08 HTML Forms. This lesson exists only in the archive; there is no current (non-archived) AI track version of ai08 yet.

Documents in this folder, in suggested order:
1. ai08 BuildBrief summary.txt — the form requirements, must-say list, lazy-form twist, and files to commit.
2. ai08 AudioLab summary.txt — the forms face-off: real versus lazy form, written findings, and submit behavior.
3. ai08 ConceptCheck summary.txt — the topics the ai08 ConceptCheck sheet checks (questions left out; they are homework).
