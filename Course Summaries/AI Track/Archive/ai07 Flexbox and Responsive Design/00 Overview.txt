Overview of: ai07 Flexbox and Responsive Design
Course: Web Design AI track (archived version)

What this lesson is about:
This archived unit makes your site responsive by direction. You verify the viewport meta tag, build a flexbox nav bar and a card row that wraps, write mobile-first media queries with a min-width 768px breakpoint, and apply max-width: 100% to images. You learn flexbox properties by name (display: flex, justify-content, align-items, flex-wrap, gap) and meet CSS Grid at recognition level. You save template.html, a skeleton that every future page starts from. The key lesson is the difference between visual order and reading order: a deliberate row-reverse rule shows that CSS can change what appears on screen but not what screen readers and the Tab key follow, which is why code order must stay logical. The matching lesson in the HTML CSS JavaScript track is html07 Flexbox and Responsive Design. This lesson exists only in the archive; there is no current (non-archived) AI track version of ai07 yet.
