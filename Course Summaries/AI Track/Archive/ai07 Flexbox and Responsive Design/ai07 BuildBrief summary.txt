Code: <meta name="viewport" content="width=device-width, initial-scale=1.0">
This viewport tag tells phone browsers to use the device's real width instead of pretending to be a wide desktop screen.

Code: @media (min-width: 768px) { ... }
A mobile-first media query: the styles inside apply only when the window is at least 768 pixels wide, so phones get the base styles and wider screens get the extra layout rules.

Code: img { max-width: 100%; }
The responsive image rule: an image can never be wider than its container, so it shrinks to fit small screens.

Key terms:
Responsive design — a site that adapts its layout to different screen widths.
viewport meta tag — tells mobile browsers how to size the page.
Flexbox (display: flex) — a CSS layout mode that arranges child items in a row or column.
justify-content — aligns flex items along the main axis.
align-items — aligns flex items along the cross axis.
flex-wrap — lets flex items wrap onto new lines.
gap — sets space between flex items.
Mobile-first — writing base styles for phones first, then adding styles for larger screens.
Media query — a CSS block that applies only under conditions such as a minimum width.
min-width — a media query condition meaning "at least this wide."
Template — a reusable page skeleton.
CSS Grid — a two-dimensional layout system, covered here only at recognition level.
flex-direction: row-reverse — displays flex items in reverse order without changing the HTML.
