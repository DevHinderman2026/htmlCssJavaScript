Overview of: ai06 Box Model and Spacing
Course: Web Design AI track (archived version)

What this lesson is about:
This archived unit covers layout polish through the box model. You direct Claude using the four rings (content, padding, border, margin) to say exactly where space goes, center a main column with max-width and margin: auto, explain shorthand values, build a card component used at least three times with a CSS hover state, and add a sticky header with position: sticky. You also learn the display values block, inline, and none. The twist is a demo page that hides paragraphs three ways: display: none, visibility: hidden, and the sr-only technique. The audio lab shows that only sr-only keeps hidden text available to screen readers, sends you to find sr-only text on real sites, and checks that styling did not change reading order. The matching lesson in the HTML CSS JavaScript track is html06 Box Model and Spacing. This lesson exists only in the archive; there is no current (non-archived) AI track version of ai06 yet.

Documents in this folder, in suggested order:
1. ai06 BuildBrief summary.txt — the layout requirements, box model must-say list, hiding-demo twist, and files to commit.
2. ai06 AudioLab summary.txt — the three-ways-to-hide audit, sr-only on real sites, and the reading-order check.
3. ai06 ConceptCheck summary.txt — the topics the ai06 ConceptCheck sheet checks (questions left out; they are homework).
