- Shorthand order: if you direct something like margin: 1rem 2rem, say what each value applies to.
- position: sticky.
- display values: block, inline, and none.
3. The twist: ask Claude to show three ways to hide an element with CSS (display: none, visibility: hidden, and the off-screen sr-only technique) by building a demo page with one paragraph hidden each way plus one visible control paragraph. That page is your AudioLab specimen. The brief notes the third technique appears on nearly every professional site.

Code: margin: 1rem 2rem;
With two values, the first (1rem) sets the top and bottom margins and the second (2rem) sets the left and right margins. This is the shorthand the brief asks you to explain when you use it.

Code: main { max-width: 60rem; margin: 0 auto; }
An example of centering a column: the width is capped, and automatic left and right margins split the leftover space evenly. (The numbers are only an example.)

Key terms:
Box model — the idea that every element is a box made of content, padding, border, and margin, from the inside out.
Content — the innermost part of the box holding text or images.
padding — space inside the border, between the content and the border.
border — the line around the padding.
margin — space outside the border, between this box and others.
max-width — the largest width an element may grow to.
margin: auto — automatic margins, used on left and right to center a block with a set width.
Shorthand — writing several side values in one property, in the order top, right, bottom, left.
position: sticky — keeps an element, such as a header, in place once scrolling reaches it.
display: block, inline, none — block elements start on a new line and fill the width; inline elements flow within text; none removes the element.
Card component — a reusable styled box for a piece of content.
sr-only — the off-screen hiding technique that keeps content readable by screen readers.
