Course: Web Design AI track (archived version)

What this lesson is about:
This folder holds study notes for the archived, older first version of the Web Design AI track. According to its README (README_v1.md), the track is an alternative pathway through the 145010 Web Design course built on two skills: directing an AI (Claude) to build exactly what you specify, and auditing web pages by audio with a screen reader, the way professional accessibility testers do. It follows the same schedule, state competencies, and December exam as the main course, and each unit is numbered to pair with the HTML CSS JavaScript track lesson of the same number (ai02 pairs with html02, and so on). Every unit follows the five-step loop of brief, direct, save, audit, commit, and every unit after ai00 has three files: a BuildBrief (what to have Claude build and the must-say vocabulary your directions must use), a ConceptCheck (questions answered in your own words), and an AudioLab (the screen reader audit, with what a correct page should sound like). GETTING_STARTED.md lists the tools needed (the Claude desktop app, a screen reader, GitHub Desktop with the repo cloned, and your unit folder), the nine standard audit moves, and the habit of checking the headings list first after every build. The archive contains units ai00 through ai08; the README describes ai09 to ai11 as coming and ai12 as shared exam prep, but none of those are in the archive. Units ai00 through ai04 also have a current (non-archived) version in the AI track, but ai05 through ai08 exist only here: there is no current (non-archived) version of those lessons yet.

Documents in this folder, in suggested order:
1. README v1 summary.txt — what the archived track is, how units are organized, the unit map, and why pages are audited by audio.
2. GETTING STARTED summary.txt — the tools to have running, how to have Claude save files, the nine audit moves, and the headings-list habit.
3. ai00 Getting Started (folder) — the workflow, the audit-moves trainer on a practice bakery page, and the first full session; matches html00 Getting Started.
4. ai01 Document Structure (folder) — the About Me page built by direction; matches html01 Document Structure.
5. ai02 Semantic HTML (folder) — header, nav, main, section, footer, lists, and em and strong; matches html02 Semantic HTML.
6. ai03 Links and Navigation (folder) — a three-page site with anchors, mailto, download, and skip links; matches html03 Links and Navigation.
7. ai04 Images Media and Tables (folder) — alt text, media controls, and accessible tables; matches html04 Images Media and Tables.
8. ai05 CSS Fundamentals (folder) — an external stylesheet and proof that CSS does not change structure, except display: none; matches html05 CSS Fundamentals. Archive only.
9. ai06 Box Model and Spacing (folder) — spacing, cards, sticky header, and three ways to hide content including sr-only; matches html06 Box Model and Spacing. Archive only.
10. ai07 Flexbox and Responsive Design (folder) — responsive layout, a page template, and visual order versus reading order; matches html07 Flexbox and Responsive Design. Archive only.
11. ai08 HTML Forms (folder) — accessible, validated forms and forms-mode auditing; matches html08 HTML Forms. Archive only.

Other files in the original lesson:
None besides the lesson folders. The archive's top level has only README_v1.md and GETTING_STARTED.md, and the lesson folders contain only markdown files plus one HTML practice page in ai00. There are no images or media files.
