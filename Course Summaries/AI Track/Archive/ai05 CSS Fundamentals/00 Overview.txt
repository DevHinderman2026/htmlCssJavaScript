Overview of: ai05 CSS Fundamentals
Course: Web Design AI track (archived version)

What this lesson is about:
This archived unit introduces CSS by direction. You have Claude style your three-page site with one external stylesheet, styles.css, linked from every page, with no inline styles or style blocks. You specify a color scheme with hex codes or named colors, two fonts with fallback stacks, link styles with a :hover state, and element, class, and id selectors used on purpose. The track treats styling as specification, like an art director, and has you verify Claude's claims by tracing them to real CSS rules. The audio lab proves that styling changes nothing a screen reader reports, except display: none, which removes content entirely. The matching lesson in the HTML CSS JavaScript track is html05 CSS Fundamentals. This lesson exists only in the archive; there is no current (non-archived) AI track version of ai05 yet.

Documents in this folder, in suggested order:
1. ai05 BuildBrief summary.txt — the stylesheet requirements, must-say list, the design-review description twist, and files to commit.
2. ai05 AudioLab summary.txt — the invisibility proof: before and after audits, the display none exception, and tracing claims to CSS rules.
3. ai05 ConceptCheck summary.txt — the topics the ai05 ConceptCheck sheet checks (questions left out; they are homework).
