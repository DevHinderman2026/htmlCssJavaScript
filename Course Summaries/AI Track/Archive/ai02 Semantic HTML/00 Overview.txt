Overview of: ai02 Semantic HTML
Course: Web Design AI track (archived version)

What this lesson is about:
This archived unit is about building pages with real semantic structure by direction. You direct Claude to build a one-page site on a topic you care about using header, nav, main, section, and footer, one h1 with h2 section headings, one ordered and one unordered list chosen for their content, and em and strong used for their meaning. A key twist is asking Claude to find and replace any generic divs it used where semantic elements belong. The audit checks the headings list, the region walk (banner, navigation, main, content information), and how the lists announce. You then build a broken copy with plain divs and hear the main region disappear, which shows why semantic elements matter even when the page looks the same. The matching lesson in the HTML CSS JavaScript track is html02 Semantic HTML.

Documents in this folder, in suggested order:
1. ai02 BuildBrief summary.txt — what to build, the must-say list, the div-checking twist, and the files to commit.
2. ai02 AudioLab summary.txt — the four-step audit including the broken.html experiment.
