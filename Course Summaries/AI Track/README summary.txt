In one sentence:
This README explains how the AI track works: you tell Claude what web page to build, check the result with your screen reader, and turn it in by pushing it to GitHub.

Main ideas:
- In this track you build web pages by giving directions to Claude. After Claude makes a page, you check it with your screen reader and then push it to GitHub.
- You read the lessons on GitHub, but you do the building in your own repository on your own computer.
- Every lesson has two files. The Lesson file tells you what to build, step by step, and how to check it. The Questions file has short questions you answer in your own words.
- To answer the questions, copy them into a Google Doc or a Word document, type your answers, and share the document with Mr. McMaster in Google Classroom.
- Lessons are numbered to match the main class (the HTML CSS JavaScript track). For example, ai01 goes with html01.
- Each lesson gets its own folder in your repository, and that folder has the same name as the lesson folder in the course repository (for example, ai00_gettingStarted).

The four tools:
1. The Claude desktop app, where you build. You tell Claude what you want and where to save it.
2. Chrome with your screen reader, where you check the page.
3. GitHub Desktop, which is how you turn in your pages.
4. Google Docs or Word, where you answer the questions.

The loop (every lesson uses the same four moves):
1. Build. Tell Claude what to make and where to save it.
2. Check. Open the page in Chrome and listen to it.
3. Fix. If something is wrong, tell Claude what you heard and have it fix the file.
4. Push. Commit and push in GitHub Desktop.

Key terms:
repository — the project folder tracked by Git and GitHub where all your lesson folders and pages live.
commit — saving a snapshot of your changes in GitHub Desktop.
push — sending your commits up to GitHub; in this course, pushing is how you turn work in.
Lesson file — the step-by-step build instructions for a lesson.
Questions file — the short written questions for a lesson, answered in a shared document.

What you are asked to do:
- Start by opening the ai00_gettingStarted folder and reading ai00_Lesson.md.
- For every lesson, build in a folder in your repository named the same as the lesson folder, push your pages, and share your question answers with Mr. McMaster in Google Classroom.

Watch out for:
- The archive folder holds the first version of this course. The README says you do not need it.
- Answers to questions must be in your own words.

Connects to:
Each AI lesson matches an HTML CSS JavaScript track lesson with the same number, such as ai01 with html01 Document Structure.
