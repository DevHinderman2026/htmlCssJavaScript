Overview of: AI Track
Course: Web Design AI track

What this lesson is about:
This is the top folder for the Web Design AI track, the AI-assisted version of the web design course (repository name webDesignAiTrack). In this track you build web pages by telling the Claude desktop app what to make and where to save it, then you check each page yourself in Chrome with your screen reader, have Claude fix anything that sounds wrong, and turn the work in by committing and pushing with GitHub Desktop. Every lesson follows the same four-move loop: Build, Check, Fix, Push. Each lesson has a Lesson file with step-by-step build and check instructions and a Questions file with short questions you answer in your own words in a Google Doc or Word document shared with Mr. McMaster in Google Classroom. Lessons are numbered to match the main HTML CSS JavaScript track, so ai01 goes with html01, and each lesson gets a folder in your repository with the same name as the lesson folder. Starting in ai02, the lessons build one growing website about your own music: a home page, then a three-page linked site, then a media page with images, audio, and a table, and a release page for one new release. By the end of the current lessons you can direct an AI to build accessible, semantic HTML pages and verify the result by ear using screen reader navigation keys.

Documents in this folder, in suggested order:
1. README summary.txt — how the AI track works: the four tools, the Build Check Fix Push loop, and how to turn in lessons and questions.

The five current lessons, in order (each is its own subfolder with its own 00 Overview.txt):
1. ai00 Getting Started — build your first page, hello.html, and learn the loop. Matches html00 Getting Started.
2. ai01 Document Structure — build an About Me page, aboutme.html, with a title, one heading level one, sections, and a comment. Matches html01 Document Structure.
3. ai02 Semantic HTML — build the home page of your music site, index.html, using header, nav, main, section, and footer, plus lists, strong, and em. Matches html02 Semantic HTML.
4. ai03 Links and Navigation — grow the site to three linked pages with a shared nav, jump links, an email link, a download link, and a skip link. Matches html03 Links and Navigation.
5. ai04 Images Media and Tables — add a media page with images and alt text, an audio player, and a track table, plus a second lesson (ai04b) that builds a release page for one new release. Matches html04 Images Media and Tables.
