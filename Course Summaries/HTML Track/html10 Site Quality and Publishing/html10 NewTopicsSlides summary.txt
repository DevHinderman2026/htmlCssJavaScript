In one sentence:
This short slideshow covers three topics the exam expects that were added to the unit: bandwidth versus latency, browser plug-ins, and content management systems (CMS).

Main ideas:
1. Bandwidth and latency are two different reasons a page can feel slow. Bandwidth is how much data moves per second, like a wider pipe, measured in megabits per second (Mbps). Latency is how long one round trip takes, like a longer pipe, measured in milliseconds (ms).
2. The truck analogy: bandwidth is how much the truck can carry; latency is how long the drive takes. Adding more trucks does not make the drive shorter.
3. Why designers care: big images use up bandwidth, and every separate file adds another round trip, which adds latency. Optimizing means making files smaller and also using fewer of them.
4. Data transmission volume: more content means more data, which loads slower on low bandwidth. Video is far larger than images, and images are far larger than text, by orders of magnitude. Mobile connections have less bandwidth, higher latency and data caps. This is why you compress images before publishing.
5. Browser plug-ins were separate programs the browser loaded to show content HTML could not handle, such as Flash (animation and games), Java applets, Silverlight and PDF readers. HTML5 gave browsers built-in audio, video and interactivity, so plug-ins died out; Flash officially ended in 2020. Today the word usually means browser extensions (ad blockers, password managers), which add features rather than embedded content. Exam framing: plug-ins extend what a browser can display, and modern HTML5 replaced most of them.
6. A CMS (content management system) stores content in a database and builds pages from templates, so you edit content in a dashboard instead of in HTML files. WordPress powers roughly 40 percent of all websites; others are Drupal, Joomla, and hosted builders like Wix and Squarespace.
7. Static site versus CMS-driven site. In a static site, which is what the class builds, the files are the pages: fast, simple, and nothing to hack, but changing content means editing code. In a CMS-driven site non-coders can update content and themes or templates control the look, but it needs hosting, updates and security care.
8. Installing and configuring a CMS, at describe level: 1. a web server with a database (usually MySQL plus PHP for WordPress); 2. upload or install the CMS software; 3. run its setup, connecting the database and creating the admin account; 4. configure it by choosing a theme (template) and setting up pages, menus and users; 5. maintain it with updates, backups and security patches. You do the configure half for real in html11 on WordPress.com, where hosting and install are already done.
9. Recap: a slow page is caused by bandwidth (too much data), latency (too many trips), or both; plug-ins were the old way to extend browsers and HTML5 mostly replaced them; a CMS is database plus templates plus dashboard, and WordPress is the giant; static versus dynamic is the idea all of this sits on.

Key terms:
bandwidth — how much data can move per second, measured in Mbps.
latency — how long one round trip takes, measured in ms.
round trip — a request going to the server and the response coming back.
data cap — a limit on how much data a (usually mobile) plan allows.
plug-in — separate software a browser loaded to display content such as Flash; mostly replaced by HTML5.
browser extension — an add-on that gives the browser extra features, such as an ad blocker.
Flash — an old plug-in for animation and games, ended in 2020.
CMS — content management system: a database of content, templates for the look, and a dashboard for editing.
WordPress — the most widely used CMS, about 40 percent of websites.
theme — a CMS template that controls how the site looks.
MySQL and PHP — the database and server language WordPress usually runs on.

Watch out for:
- Do not mix up bandwidth and latency: bandwidth is how much, latency is how long. More bandwidth does not fix latency.
- Faster pages need both smaller files and fewer files.
- Exam wording: plug-ins extend what a browser can display; extensions add features.
- CMS is describe level here; you are not expected to install one.
