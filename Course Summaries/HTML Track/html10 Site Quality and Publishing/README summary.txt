In one sentence:
This is the teacher-facing package description written for the old html12 SEO and Accessibility lesson, with a note on top saying it now belongs to the merged html10 unit and that you should start with html10_UnitGuide.md.

Main ideas:
1. Version 2 note at the top: this folder is now the merged html10 Site Quality and Publishing unit. The Seo files are the former html12 and the Publish files are the former html13. Start with the Unit Guide.
2. The rest describes only the SEO and accessibility half of the unit. It lists eleven files:
- html10_SeoSlides.md: slides on SEO and accessibility (title tags, meta descriptions, semantic HTML, heading hierarchy, alt text, WCAG, screen readers, color contrast, ARIA labels, keyboard navigation), about 20 to 30 minutes of teaching.
- html10_SeoStudyGuide.md: 23 vocabulary terms, SEO and accessibility cheat sheets, ODE competencies 6.5.14, 6.1.2, 6.1.4 and 6.5.10, review questions and resource links.
- html10_SeoWalkthrough.md: a guided audit of a bad example, fill-in-the-blank SEO and accessibility audits, the good example, and a reusable checklist.
- html10a_Task.html: a flawed restaurant site with labeled SEO problems, a 30 to 45 minute task.
- html10a_Task_Solutions.html: the fixed restaurant site.
- html10b_Task.html: a flawed tech gadget store with 20 labeled accessibility problems, a 30 to 45 minute task.
- html10b_Task_Solutions.html: the fixed store.
- html10_SeoDIYTask.md: audit one of your own earlier projects with a 13-item SEO checklist and a 13-item accessibility checklist, a documentation template, a Priority 1, 2 and 3 fix plan, testing requirements and a rubric.
- html10_SeoDIYTask_Solutions.html: a fully optimized portfolio example.
- html10_SeoGimkit.csv: 35 game-style quiz questions.
- html10_SeoGoogleQuiz.csv: 31 multiple-choice questions for Google Forms.
3. Competencies: 6.5.14 SEO, 6.1.2 planning with accessibility (ADA), 6.1.4 proofreading and quality assurance, 6.5.10 usability testing.
4. Three suggested lesson flows for teachers. Option 1 is lecture plus tasks over 2 to 3 days (slides and walkthrough, then task a, then task b). Option 2 is flipped over a week (read the study guide at home, then Gimkit review, both tasks, and a debrief with the Google quiz). Option 3 is project-based over 2 weeks (instruction, both tasks, the DIY audit of your own project, then presentations and assessment).
5. Difficulty: slides and study guide are beginner level, the walkthrough is guided beginner practice, tasks a and b are intermediate (15 to 20 problems each), and the DIY task is advanced because you audit your own real code.
6. Free tools used: WebAIM Contrast Checker, Google Lighthouse (in Chrome DevTools), the WAVE browser extension, and the NVDA screen reader (optional).
7. Teacher tips: SEO and accessibility are connected, so fixing one often helps the other; focus on practical daily skills; demonstrate navigating with only the Tab key; stress that accessibility is both the law and the ethical thing to do; have students predict problems before revealing answers.
8. Standards claims: valid HTML5, commented code, WCAG 2.1 Level AA, tasks completable in 30 to 45 minutes, no external dependencies.
9. Quick start: present slides, walk through task a with the walkthrough, assign task a, assign task b, assign the DIY task, then assess with Gimkit or the Google quiz.

Key terms:
WCAG 2.1 Level AA — the accessibility standard the materials follow.
Lighthouse — Google's built-in page audit tool in Chrome DevTools.
WAVE — a free accessibility checker from WebAIM.
WebAIM Contrast Checker — a free web tool that measures text-to-background contrast.
NVDA — a free Windows screen reader.

- Heads up: task a has 15 numbered problems to fix, as the starter file shows; the README's list of 8 issue types only groups them, so fix all 15.
- Heads up: the README covers only the SEO and accessibility half and is older than the Unit Guide. Use the Unit Guide for the whole unit, including the Publish files, New Topics slides, tasks c to e and the Extension task.
