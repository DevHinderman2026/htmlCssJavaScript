Lesson: html06 Box Model and Spacing
Type of document: walkthrough

In one sentence:
This guided walkthrough has you build a card component one layer at a time (padding, border, margin), check it with the X-ray trick, and then build three demo pages that show the display property, fixed headers and footers, and relative-plus-absolute positioning.

Main ideas:
Part 1, the card component (steps 1 to 5):
1. Step 1, basic card. Create card.html with an internal style sheet (a style element in the head). The first rule sets box-sizing border-box on every element using the star selector. The card is a div with class card, width 300px, and a light gray background (#f5f5f5). Inside it are an h2 with class card-title (24 pixel bold text) and a p with class card-body (14 pixel gray text). With no spacing yet, the card looks flat and the text touches the edges.
2. Step 2, padding. Add padding: 20px to the card, which puts 20 pixels of space inside all four sides so the content "breathes." On the title set margin-top 0 to remove the browser's default top margin, plus padding-bottom 10px. On the body text set margin 0. Try padding 40px, and try padding: 10px 20px (10 on top and bottom, 20 on left and right). Question asked: does padding make the card wider? Answer: with border-box, no; with content-box, yes.
3. Step 3, border. Add border: 2px solid #333 (2 pixel width, solid style, dark gray color) and border-radius: 8px for rounded corners. Experiments: a 4px dashed #999 border, a 1px dotted #ccc border, and border-radius 0px versus 16px.
4. Step 4, margin. Add margin: 30px, which puts 30 pixels of empty space outside all four sides of the border. Add a second card (Card One and Card Two) to see the gap margin creates between them. Experiments: margin 10px brings the cards closer, margin 0 makes them touch, and margin-left: 50px sets only the left side.
5. Step 5, the X-ray trick. Because dev tools (Inspect) are off on school computers, add * { outline: 1px solid red; } at the very top of the CSS. Every element gets a thin red edge, and since outlines take no space nothing moves. What you learn: the background color fills both the content and the padding; the border is the line you set; the margin is the empty space outside the border. Changing padding from 20 to 40 grows the background area and pushes the text farther from the border. Changing margin from 30 to 60 leaves the card the same size but grows the space around it. Change both back and delete the outline line afterward.

Part 2, display (step 6):
6. Create display-demo.html. It uses four classes. block-box is display block, 200px wide, 80px tall, with padding, a border, and margin-bottom 20px; two of these stack on separate lines. inline-box is display inline on span elements with padding 5px 10px and margin-right 10px; three of them sit in a line like words. inline-block-box is display inline-block, 150px by 60px; three of them sit side by side but keep their set size. hidden-box is display none, so that element takes no space at all.
7. Experiments: change block-box to inline and the width is ignored; change inline-box to block and each one takes the full width; change inline-block-box to block and they stack vertically.

Position, fixed header and footer (labeled Part 7 in the source):
8. Create layout-demo.html. The body has margin 0. The header is position fixed with top 0, left 0, right 0, width 100 percent, height 60px, a blue background, white text, padding 15px 20px, and z-index 100 so it stays on top. The header h1 has margin 0.
9. The main element gets margin-top 60px to match the header height so the header does not cover it, plus padding 20px and min-height: calc(100vh - 180px) to fill the screen. The calc function does math with mixed units; 100vh means 100 percent of the viewport height.
10. The footer is position fixed with bottom 0, left 0, right 0, width 100 percent, height 60px, a dark background, white centered text, and padding. The body gets margin-bottom 60px so the last content is not hidden behind the footer. Filler paragraphs make the page long enough to scroll.
11. Experiments: change the header to position absolute and it scrolls away with the page; remove main's margin-top and the header covers the content; change z-index from 100 to 1 and check whether it still works.

Relative and absolute positioning (labeled Part 8 in the source):
12. Create positioning-advanced.html. A container div is position relative, 400 by 300 pixels, with a border. Setting relative on the parent creates a positioning context, meaning absolute children measure their offsets from this box instead of from the page.
13. Three 100 by 100 pixel child boxes are position absolute. box1 uses top 10px and left 10px to sit in the top-left corner. box2 uses top 50 percent and left 50 percent plus transform: translate(-50%, -50%) to sit exactly in the center; the transform pulls the box back by half its own size so its middle, not its top-left corner, lands on the center point. box3 uses bottom 10px and right 10px to sit in the bottom-right corner. The boxes also use display flex with align-items center and justify-content center to center their label text.
14. Experiments: remove position relative from the container and see where the boxes go (they position against the page instead); move box1 to top 50px left 100px; set box3 to bottom 0 right 0 to see whether it sticks to the corner.

Summary and challenge:
15. Takeaways: box model is content plus padding plus border plus margin; border-box prevents width surprises; display values block, inline, inline-block, none; position values static, relative, absolute, fixed; the X-ray trick shows every edge.
16. Challenge list: add a second card and vary the spacing between them; make cards inline-block so they sit side by side; add an absolutely positioned badge in a card's corner; check changes with the X-ray trick; give a card four different paddings with padding: 10px 20px 30px 40px. Turn the X-ray trick on after each change, then remove it.

Key terms:
card component — a reusable styled box holding a title, text, and sometimes a button
padding, border, margin — the inside space, edge line, and outside space of a box
border-radius — rounds corners
X-ray trick — * { outline: 1px solid red; } to see every box edge without dev tools
display: block, inline, inline-block, none — the four flow behaviors demonstrated
position: fixed — pinned to the browser window while scrolling
position: relative on a parent — creates the positioning context for absolute children
position: absolute — placed by offsets inside the nearest positioned ancestor
z-index — stacking order; higher is on top
calc() — CSS function that does arithmetic, such as 100vh minus 180px
vh — viewport height unit; 100vh is the full window height
transform: translate(-50%, -50%) — shifts an element back by half its own width and height, used for exact centering
min-height — the smallest height an element is allowed to be

What you are asked to do:
- Create card.html and build the card through steps 1 to 5, doing each "Try This" experiment.
- Create display-demo.html and do its three experiments.
- Create layout-demo.html and do its three experiments.
- Create positioning-advanced.html and do its three experiments.
- Optionally complete the five challenge modifications.

Watch out for:
- Browsers add default margins to headings and paragraphs; set margin-top 0 or margin 0 when you want tight spacing.
- A fixed header needs matching top space on main, and a fixed footer needs matching bottom space on the body.
- Without position relative on the parent, absolute children position against the page.
- Delete the X-ray outline when finished.
Heads up: the walkthrough really has four parts, as the README says; its headings just jump from Part 2 to Part 7 and Part 8 because of leftover old numbering. Nothing is missing, so treat Parts 7 and 8 as Parts 3 and 4.
