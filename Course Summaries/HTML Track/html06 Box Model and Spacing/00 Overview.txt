Overview of: html06 Box Model and Spacing
Course: HTML CSS JavaScript track

What this lesson is about:
This lesson teaches how CSS controls the space around and inside every element. Every element is a box made of four layers from the inside out: content, padding, border, and margin. You learn to set each layer with shorthand values, and to use box-sizing border-box so the width you write is the width you get. The second half covers the display property (block, inline, inline-block, none), which decides how elements flow, and the position property (static, relative, absolute, fixed, and in the extension, sticky), which decides where they sit, along with offsets and z-index. Because dev tools are disabled on school computers, the lesson teaches the X-ray trick, a temporary outline on every element, plus the W3C validator and paper diagrams for debugging. You leave able to build a spaced card component and a page with a fixed header, sidebar, content area, and fixed footer.
