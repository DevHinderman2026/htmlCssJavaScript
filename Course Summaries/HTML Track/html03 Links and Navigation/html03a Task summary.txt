Course: HTML CSS JavaScript track
Lesson: html03 Links and Navigation
Type of document: task starter file

In one sentence:
This starter file has you build a one-page "Local Businesses Directory" whose navigation, jump list, and footer all use same-page anchor links to sections marked with ids.

Main ideas:
The head already has the doctype, lang en, meta charset, viewport meta tag, and an empty title element. The body contains only TODO comments. Every link on this page is a same-page link: the header nav, the aside, and the footer all jump to sections using the number sign plus an id. The practice point is pairing each id with matching links, and checking that the browser's address shows the fragment after you click.

Key terms:
id — unique name on an element that a link can target.
Fragment identifier — the number sign plus an id, such as #events.
header, nav, main, section, aside, footer — page regions used.
Jump navigation — a list of links to sections on the same page.

What you are asked to do:
1. Put "Local Businesses Directory" in the title (the TODO suggests this title).
2. Create a header with id="top" containing an h1 "Local Businesses Directory" and a nav with links Home, Featured, Services, and Events. Their hrefs are #top for Home, #featured, #services, and #events.
Code: <a href="#featured">Featured</a>
This link jumps to the section on this page whose id is featured.
3. Create a main element to wrap all the page content.
4. Add a section with id="featured", an h2 "Featured Businesses", and a paragraph describing featured local businesses.
5. Add a section with id="services", an h2 "Services Directory", and paragraphs describing service categories, for example Restaurants, Retail Shops, and Professional Services.
6. Add a section with id="events", an h2 "Community Events", and a description of upcoming local events.
7. Create a "Jump Navigation" aside with a list of anchor links to #featured, #services, #events, and #top.
8. Close the main element.
9. Create a footer with a copyright notice, a secondary nav with links Home, Featured, Services, and Events, and a Back to Top link pointing to #top.
Challenge at the end:
1. Test all the anchor links; each should jump to the correct section.
2. Check that the address shows the fragment identifier, such as #featured, after clicking.
3. Make sure all tags are properly closed.
4. Validate at validator.w3.org.
Correction: these are same-page fragment links (an href starting with a number sign, such as #featured), not relative links to other files. The header TODO calls them "relative links", but the code it asks for is fragment links.

Watch out for:
- Each id must be spelled exactly the same in the section and in every link that points to it, including the number sign in the link.
- Only one element may have each id; do not reuse "top".
- The aside goes inside main, before main closes.
