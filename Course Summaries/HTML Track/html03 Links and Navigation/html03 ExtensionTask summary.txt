In one sentence:
For fast finishers, this task adds two real-world navigation patterns to your multi-page mini-site: a breadcrumb trail on every subpage and a skip link on every page.

Main ideas:
1. This is extra credit with no points and no rubric. Finish the regular html03 tasks first.
Heads up: each extension task sets its own terms, so for this one go by what it says (no points, no rubric), even though the html02 extension task says Mr. M assigns points. If extra credit matters for your grade, check with Mr. McMaster.
2. Breadcrumb trail. On every page except the home page, add a line near the top showing where the visitor is, such as Home, then Menu, then Desserts, separated by greater-than signs. Each earlier step (ancestor) is a working link; only the current page is plain text. Use a nav element with an ordered list inside, because breadcrumbs are a sequence and ol is the semantically correct list for a sequence.
3. Skip link. As the very first element inside the body on each page, add a link with the text "Skip to main content" pointing to #main-content, and give your main content area id="main-content". Keyboard users, including screen reader users, can then jump past the navigation instead of tabbing through every nav link on every page.
Code: <a href="#main-content">Skip to main content</a>
This link jumps to the element whose id is main-content.
4. How to test the skip link: click in the browser's address bar, then press Tab once. The skip link should be the first thing that receives focus, and activating it should move you to the main content.

Key terms:
Breadcrumb — a trail of links showing the path from the home page to the current page.
Ancestor — a page above the current one in the site's hierarchy.
Skip link — a first-in-page link that jumps past repeated navigation to the main content.
Focusable element — something Tab can land on, such as a link.
id="main-content" — the target id for the skip link.

What you are asked to do:
Commit your updated mini-site pages, with breadcrumbs on all subpages and a skip link on every page.
Done when:
- Every subpage has a breadcrumb nav with an ol inside.
- Every breadcrumb ancestor is a working relative link, and the current page is plain text.
- Every page's first focusable element is the skip link.
- The skip link's target exists and the jump works.
- Pushed to GitHub.

Watch out for:
- The skip link must come before the header and nav, as the very first thing in the body.
- Do not make the current page a link in the breadcrumb.
- Use ol, not ul, for breadcrumbs.
