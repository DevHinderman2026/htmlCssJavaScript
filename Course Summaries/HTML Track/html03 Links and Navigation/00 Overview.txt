Overview of: html03 Links and Navigation
Course: HTML CSS JavaScript track

What this lesson is about:
This lesson teaches how pages connect. You learn the anchor element (a) and its href attribute, and the difference between absolute links (full web addresses for other sites) and relative links (file paths within your own site, including going into subfolders and up with two dots and a slash). You learn the target attribute, especially target="_blank" for opening external sites in a new tab, and page anchors: marking a spot with an id and jumping to it with a number sign plus the id, including Back to Top links. Sub-lesson 03b adds email links with mailto:, phone links with tel:, download links with the download attribute, and consistent navigation in the header and footer of every page. The main project is a three-page mini-site (index.html, about.html, contact.html) kept in one folder. The extension adds breadcrumbs and a skip link for keyboard and screen reader users. You leave able to build and test a small multi-page site with working navigation.
