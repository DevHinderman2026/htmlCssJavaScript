In one sentence:
This study guide covers 24 vocabulary terms on links and navigation, a cheat sheet of link patterns, the ODE competencies, ten common mistakes, study tips, and rules for naming ids (its practice questions are left out of these notes).

Main ideas:
1. Link fundamentals. The anchor element (a) makes hyperlinks. href holds the destination. Link text is what people see and click. An absolute link is a complete address including the protocol, such as https://, and works from anywhere. A relative link is a path from the current page and works within your own site.
2. Where links open. The target attribute controls this. target="_blank" opens a new tab or window and keeps the original page open. target="_self" opens in the same tab, which is the default.
3. Page anchors. The id attribute gives an element a unique name. A link to the number sign plus that id jumps there; the number sign part is the fragment identifier. To reach a section on another page, write the file name then the fragment, such as index.html#contact. For Back to Top, give the header id "top" and link to "#top".
4. Navigation. A navigation menu is a set of links for moving between pages, usually in the header or footer, wrapped in the nav element. The cheat sheet's layout: a header with an h1 and a nav of Home, About, Services, and Contact; a main; and a footer with a copyright line and a second nav of Home, Privacy, and a mailto Support link. A site map is an overview of all pages and how they connect. Breadcrumb navigation is a secondary navigation showing the user's path through the site.
5. Email and download links. An email link uses the mailto: protocol and opens the default email app. A query string adds extra parameters after a question mark, such as ?subject=Hello&body=Message. Spaces in the subject or body are written as %20, for example subject=Help%20Needed. The download attribute forces a file to download, and giving it a value renames the file.
Code: <a href="mailto:support@example.com?subject=Help%20Needed">Contact Support</a>
This email link pre-fills the subject Help Needed, with %20 standing for the space.
6. Best practices. Use descriptive link text so screen reader users know where a link goes. External links should open in a new tab. Keep navigation consistent on every page. Organize files into folders to make relative linking easier. The example site folder has index.html, about.html, contact.html, a styles folder with style.css, an images folder with logo.png, and a files folder with resume.pdf.
7. ODE competencies. 6.2.1 Understand Absolute and Relative Links. 6.2.2 Create Internal Page Anchors and Fragment Links. 6.2.3 Create Email Links and Download Links. 6.5.2 Design Site Structure and Navigation: planning multi-page sites with consistent navigation, organizing folders, and intuitive menus.
8. Study tips. Test every link as you build. Use relative paths for your site and absolute ones for others. Put an id on every major section. Copy the same nav code to every page. Check file name capitals carefully, because about.html and About.html are different on some servers. Match paths to your real folder structure. Write descriptive link text. Test in more than one browser.
9. id naming rules. Good examples: contact-section, mainNav, testimonials. Avoid starting with a number (1section), spaces (contact section), and capitals with spaces (Contact Section), which can cause linking problems.

Key terms:
a (anchor tag) — creates hyperlinks.
href — the destination address or path.
Link text — the visible clickable text.
Absolute link — a full URL with protocol.
Relative link — a path relative to the current page.
Target attribute — controls where the link opens.
target="_blank" — new tab or window.
target="_self" — same tab, the default.
Fragment identifier — the number sign part that points to a section.
id attribute — a unique identifier that can be linked to.
Page anchor — a spot marked with an id for internal linking.
Navigation menu — links for moving between pages.
nav element — semantic container for navigation links.
Site map — an overview of all pages and their connections.
Breadcrumb navigation — secondary navigation showing the user's path.
Email link — a link using mailto: to open the email app.
mailto: protocol — the URL scheme that launches email.
Download attribute — forces a download instead of opening.
Query string — parameters after a question mark in a URL.
Protocol — the start of a URL saying how to access it: http, https, mailto, ftp, and so on.
Accessibility in links — descriptive link text for screen readers.
External links — links to other websites.
Navigation consistency — the same menus on every page.
Folder structure — organizing files into directories.

Watch out for:
The guide's ten common mistakes:
1. Forgetting href entirely.
2. Using a full absolute address for your own pages instead of a relative link.
3. Wrong relative path, such as about.html when the file is actually in a pages subfolder.
4. Forgetting the number sign in a fragment link (href="about" instead of "#about").
5. Vague link text like "Click here" instead of "About Our Team".
6. Not using target="_blank" for external links, so they replace your site.
7. Duplicate ids; the browser only goes to the first match.
8. Not encoding spaces in email links; use %20.
9. Leaving the protocol off absolute links (google.com instead of https://google.com).
10. Overusing target="_blank"; internal navigation should stay in the same tab.
