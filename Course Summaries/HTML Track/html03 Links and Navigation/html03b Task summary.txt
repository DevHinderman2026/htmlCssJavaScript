Course: HTML CSS JavaScript track
Lesson: html03 Links and Navigation
Type of document: task starter file

In one sentence:
This starter file has you build the home page of a "Sports and Recreation Hub" site that mixes every link type: links to other pages, same-page anchors, an external link, an email link, and a phone link.

Main ideas:
The head has the doctype, lang en, meta charset, viewport meta tag, and an empty title. The body is TODO comments only. The key lesson is telling link types apart. The main and footer navigation point to other files (index.html, sports.html, classes.html, contact.html), which do not exist for this exercise, so those links will not actually open anything. The Quick Links and Back to Top are same-page anchors that should work. The email link opens a mail app, and the external link opens in a new tab.

Key terms:
Relative link to another page — an href of a file name, such as sports.html.
Same-page anchor — an href of the number sign plus an id, such as #events.
target="_blank" — opens an external link in a new tab.
mailto: — email link.
tel: — phone link.
id="top" — marks the header so Back to Top can reach it.

What you are asked to do:
1. Add a page title; the TODO suggests "Sports and Recreation - Home" (written with an ampersand in the source).
2. Create a header with id="top" and the site title "Sports and Recreation Hub", plus a main navigation with links Home, Sports, Classes, and Contact pointing to index.html, sports.html, classes.html, and contact.html. The comment stresses these are separate-page links, not same-page anchors.
3. Create a main element for the home page content, with an h1 or h2 "Welcome to Sports and Recreation" and a welcoming paragraph.
4. Create a section with id="featured" for "Featured Sports", with an h2 and a list of sports: Basketball, Soccer, Tennis, Swimming, Rock Climbing.
5. Create a section with id="events" for "Upcoming Events", with an h2 and a description of upcoming events including specific dates, times, or details.
6. Create an aside for "Quick Links" with an h3 and a list of internal anchor links to Featured Sports (#featured) and Upcoming Events (#events), plus an external link to a sports website using target="_blank".
7. Create a footer with copyright text; footer navigation linking to all four pages (Home, Sports, Classes, Contact); an email link; a phone link; and a Back to Top link to #top.
Code: <a href="mailto:info@sportsrec.com">Contact us by email</a>
This is the email link the TODO gives; it opens a message to info@sportsrec.com.
Code: <a href="tel:+1-555-0100">Call us</a>
This is the phone link the TODO gives.
Challenge, testing your links:
1. Test the main and footer navigation links; they point to other pages and will not navigate unless those pages exist.
2. Test the anchor links (Quick Links and Back to Top); they should jump within this page.
3. Click the email link; it should open your email client.
4. Click the external link; it should open in a new tab.
5. Verify all tags are properly closed.
6. Validate at validator.w3.org.
Heads up: unlike html03a, no TODO says where to close main. Keep both sections and the aside inside main and close main just before the footer, so all the page content sits in the main region.
In the source, every "and" in "Sports and Recreation" is written as an ampersand character.

Watch out for:
- Know which links go to other files and which jump within the page; the number sign makes the difference.
- External links need the full address with https:// and target="_blank".
- Back to Top only works if the header really has id="top".
