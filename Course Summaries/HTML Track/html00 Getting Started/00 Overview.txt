Overview of: html00 Getting Started
Course: HTML CSS JavaScript track

What this lesson is about:
This is the setup lesson that comes before any HTML. It gets Git, GitHub Desktop, and VS Code working on your lab computer and teaches the workflow you will use all year: edit, save, commit, push, refresh GitHub. On the first day you create a test repository called github-desktop-test, add one Markdown file, commit it, publish it to GitHub, and turn in the link through Google Classroom. On the second day you learn the parts of the VS Code window, install the Live Preview, Live Server, and Convert Markdown to PDF extensions, and add a Markdown About Me file and a Hello World HTML file to the same repo. You also learn the Git status letters U, M, A, D, and R that VS Code shows next to files, and why GitHub shows HTML files as code until a later lesson on GitHub Pages. You leave able to create, commit, and push files on your own.

Documents in this folder, in suggested order:
1. GitHub Desktop Student Guide summary.txt — day one: install Git, sign in, create and publish the github-desktop-test repo, submit the link.
2. VSCode and GitHubDesktop Walkthrough summary.txt — day two: VS Code tour, extensions, create Markdown and HTML files, push, and compare GitHub before and after.

Other files in the original lesson:
None. The original folder contains only these two Markdown documents; there are no images, media, or starter files.
