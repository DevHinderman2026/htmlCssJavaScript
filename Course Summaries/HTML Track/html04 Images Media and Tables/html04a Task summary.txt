8. The footer says "Task complete! Review your alt text and captions for clarity."

Key terms:
img — the image element.
src — path to the image file.
alt — text description for screen readers.
width and height — size in pixels; they reserve space so the page does not jump when the image loads (layout shift).
figure and figcaption — container and caption for an image.
style="max-width: 100%; height: auto;" — CSS that lets an image shrink to fit the screen.
