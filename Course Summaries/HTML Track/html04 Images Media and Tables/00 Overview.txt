Overview of: html04 Images Media and Tables
Course: HTML CSS JavaScript track

What this lesson is about:
Lesson 04 teaches how to put images, video, audio, and data tables into a web page, in three sub-lessons: 04a images, 04b media, and 04c tables. You learn the img element with its required src and alt attributes, when to use JPG, PNG, SVG, or WebP, how width and height reserve space, and how figure and figcaption tie a caption to a picture. You learn the video and audio elements with controls and multiple source files, and how to embed a YouTube video with an iframe using the embed URL. You learn table structure (table, caption, tr, th, td), merging cells with colspan and rowspan, and making headers accessible with scope. Accessibility runs through everything: alt text, iframe titles, and proper header cells all help screen reader users. The graded project adds a photo gallery page, a self-made 20-second Lego stop-motion promo video, and a comparison table to your Lesson 03 mini-site, with no CSS yet.
