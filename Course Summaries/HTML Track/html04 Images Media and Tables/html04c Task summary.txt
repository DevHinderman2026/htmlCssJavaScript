In one sentence:
This practice starter page has you build three data tables, a simple one, one using colspan, and one using rowspan, and includes a finished accessible table as a reference.

Main ideas:
1. The page is titled "Table Task" with the h1 "HTML Tables Task" and says it practices captions, header cells, colspan, and rowspan. The head contains a small style block that only draws table borders so you can see rows and cells; its comment says it is CSS from Lesson 05 and to leave it alone.
2. Each TODO comment includes a text drawing of how the finished table should look, and each section has a placeholder of three underscores where your table goes.
3. Section "Simple Table" (id simple-table) reminds you: use th for header cells and td for data cells, and put each row in its own tr.
4. Section "Table with colspan" (id colspan-table) explains that colspan makes one cell stretch across more than one column; for example colspan="2" makes a cell as wide as 2 columns.
5. Section "Table with rowspan" (id rowspan-table) explains that rowspan makes one cell stretch down across more than one row; for example rowspan="2" makes a cell as tall as 2 rows.
6. Reference section "Accessible Table" (id accessible-table) is already done; just read it. It explains that the scope attribute tells screen readers what a header cell labels: scope="col" labels the column below it, and scope="row" labels the row beside it. The table has the caption "Product Performance Report", column headers Product, Q1 Sales, and Q2 Sales (each with scope col), and two rows whose first cell is a row header with scope row: Widget A with $25,000 and $30,000, and Widget B with $15,000 and $18,000.
7. The footer says to open the page in a browser and compare each table to the drawing in its TODO comment.

Key terms:
table — container for tabular data.
caption — table title.
tr — a table row.
th — a header cell.
td — a data cell.
colspan — number of columns a cell spans.
rowspan — number of rows a cell spans.
scope — tells screen readers whether a th labels a column (col) or a row (row).

What you are asked to do:
TODO 1, simple table: caption "Student Grades"; header row of th cells Name, Math, English, Science; data rows Alice 95, 87, 92; Bob 88, 91, 85; Carol 92, 94, 89.
TODO 2, colspan table: caption "Quarterly Sales by Region"; header row Region, Q1, Q2, Q3; data rows East $50,000, $55,000, $60,000 and West $45,000, $48,000, $52,000; then a last row with ONE cell saying "All amounts are in US dollars." using colspan="4" so it stretches across all 4 columns.
Code: <tr><td colspan="4">All amounts are in US dollars.</td></tr>
This last row has a single cell that counts as four columns wide.
Rule to remember: every row must add up to the same number of columns.
TODO 3, rowspan table: caption "Product Inventory"; header row Product, Location, Quantity; then Laptop, Warehouse A, 15, where the Laptop cell has rowspan="2" so it stretches into the next row; then a row with only 2 cells, Warehouse B and 10, without typing Laptop again because the Laptop cell already fills that spot; then Monitor, Warehouse A, 20.
Rule to remember: a cell with rowspan="2" also takes a spot in the row below, so that row gets one fewer cell.

Watch out for:
- Do not repeat a cell that is already covered by a rowspan from the row above; that pushes the row out of line.
- A colspan that does not match the column count leaves a gap or creates an extra phantom column.
- Header cells should be th, not td, so screen readers announce them properly; add scope for extra clarity.
