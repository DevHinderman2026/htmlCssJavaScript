In one sentence:
This independent project has you restyle your About Me page from html01 using only an external stylesheet named styles.css with at least 10 rules.

Main ideas:
1. HTML stays nearly unchanged. Start with your html01 About Me page (or the provided example), keep the HTML clean, add exactly one link element in the head to connect the stylesheet, and add no inline styles.
2. The stylesheet is a new file named styles.css in the same folder as the HTML.
3. Plan before writing CSS: decide the look of the body (background, font), the headings (size, color, alignment), and the paragraphs (spacing, color), which text to highlight with classes, and whether a header or footer gets special styling with an ID.
4. Suggested structure: element selector rules (body, h1, p), class rules (.highlight, .intro), an ID rule for footer, and more rules until you reach 10 or more.
5. Testing: open the HTML in a browser, confirm every style applies, check colors, fonts, and text properties, and make sure the page is readable and professional.
6. Example project. The example HTML links a Google Font (Poppins, weights 400 and 700) and styles.css. It has a div with id="header" holding the h1 "About Me" and a paragraph with class="intro"; h2 sections "Who I Am", "My Interests" (including a paragraph with class="highlight"), and "My Skills" with a list of HTML, CSS, and JavaScript (learning); and a div with id="footer" holding a copyright line. The example CSS styles body (Poppins font, light gray background #f0f0f0, dark text, line-height 1.6, no margin, 20px padding), h1 (dark blue, centered, 48px, weight 700), h2 (a 2px solid blue bottom border with padding under it), p (16px, 15px bottom margin), .intro (20px, italic, gray), .highlight (light yellow background, brown text, padding, a 4px yellow left border, bold), the header ID (blue background, white text, padding, rounded corners with border-radius 8px, bottom margin, centered), the footer ID (dark background, white text, centered, padding, top margin, a 3px blue top border), and li (8px bottom margin). The document stresses this is only an example; your project should use your own About Me content.

Key terms:
external stylesheet — a separate .css file linked from the head.
link element — connects the HTML to styles.css.
element, class, and ID selectors — target a tag type, a class (dot), or one unique element (hash sign).
color and background-color — text color and fill color.
font-family, font-size, font-weight — typeface, size, boldness.
text-align, line-height, text-decoration, letter-spacing — alignment, line spacing, underline and similar lines, character spacing.
padding and margin — space inside and outside an element.
border — a line around an element or along one side.
font-style: italic and border-radius — used in the example for slanted text and rounded corners.
a:hover — a selector that styles a link while the pointer is over it (bonus).
transition — makes style changes animate smoothly (bonus).

What you are asked to do:
Requirements:
1. HTML: start from your html01 About Me page; keep it clean; add one link element in the head; no inline styles.
2. Create styles.css in the same folder with at least 10 CSS rules, including at least 2 element selectors, at least 2 class selectors, and at least 1 ID selector.
3. Use at least one property from each category: colors (such as color, background-color); fonts (such as font-family, font-size, font-weight); text properties (such as text-align, line-height, text-decoration, letter-spacing).
4. Nice-to-have additions: Google Fonts for at least one element; hex codes for at least 3 colors; rgb() for at least 1 color; padding or margin for spacing; a border to highlight important elements.
Checklist before submitting:
- HTML file is clean, with no inline styles.
- External styles.css is created and linked.
- At least 10 CSS rules.
- At least 2 element selectors, at least 2 class selectors, at least 1 ID selector.
- Uses colors (at least 3 hex colors, 1 rgb color).
- Uses fonts (font-family, font-size, font-weight).
- Uses text properties (text-align, line-height, text-decoration).
- Page looks professional and is readable.
- HTML and CSS are valid.
Bonus challenges:
1. Add a Google Font from fonts.google.com.
2. Use 3 or more hex colors in a cohesive color scheme.
3. Add hover effects with a:hover.
4. Responsive design: adjust padding and font size for mobile.
5. Advanced selectors such as p:first-child or h2:nth-of-type(2).
6. Optional animations with transition.
Submission: two files in the same folder that work together without errors: aboutMe.html (your styled About Me page) and styles.css (your external stylesheet). No point values or due date are given.

Watch out for:
- Do not add style attributes or a style element; everything goes in styles.css.
- The stylesheet does nothing unless the link element is in the head and the file name matches.
- Correction: treat at least 3 hex colors and at least 1 rgb() color as required, because the checklist requires them; the requirements list only calls them nice-to-have, and doing them satisfies both.
- Heads up: the example CSS has only 9 rules, one short of the required 10, so if you start from it, add at least one more rule of your own.
