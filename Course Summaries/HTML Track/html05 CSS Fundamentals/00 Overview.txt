Overview of: html05 CSS Fundamentals
Course: HTML CSS JavaScript track

What this lesson is about:
Lesson 05 introduces CSS, the language that controls how HTML looks. You learn the three ways to add CSS (inline style attributes, an internal style element in the head, and an external .css file connected with a link element) and why the external file is best practice. You learn how a rule is built from a selector and a declaration block of property: value pairs, and the three basic selectors: element, class (with a dot), and ID (with a hash sign). You practice colors written as names, hex codes, and rgb() values, font properties including Google Fonts, and text properties such as text-align, line-height, text-decoration, and letter-spacing. You also get a first look at the cascade and specificity, which decide which rule wins. The substitute-day lesson adds rgba(), hsl(), combined selectors, units like rem and percent, and a first taste of the box model. By the end you can build a separate stylesheet and restyle a page without touching its HTML.
