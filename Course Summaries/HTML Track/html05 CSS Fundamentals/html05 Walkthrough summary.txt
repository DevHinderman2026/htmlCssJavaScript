In one sentence:
This step-by-step walkthrough takes one plain HTML page and styles it three ways, inline, internal, then external, and then builds up the external stylesheet with colors, Google Fonts, and text properties.

Main ideas:
1. You have already seen CSS. In Lesson 04, the style attribute with max-width: 100% and height: auto on an image was an inline style, and the small style block that drew table borders was an internal stylesheet. This lesson explains both and adds the third method, the one real websites use.
2. Part 1, plain HTML. Create practice.html: a standard HTML5 page titled "My Styled Page" with an h1 "Welcome to CSS!", a paragraph about the three CSS methods, a paragraph with class="highlight" saying it should stand out, and a div with id="footer" containing a copyright line. Open it in a browser; it looks plain.
3. Part 2, inline styles. Add a style attribute directly to a tag. Fill-in: the h1 gets style="color: blue;". The highlight paragraph gets style="background-color: yellow;". You can put several properties in one style attribute, separated by semicolons, for example white text on a navy background.
4. Part 3, internal stylesheet. Instead of styling every tag, put a style element in the head. It starts with an h1 rule (color blue, font-size 32px) and a p rule (color #333333, font-size 16px). Fill-ins: a .highlight rule with yellow background and bold font-weight, and a rule for the ID footer with background #333333, white text, centered text, and 20px padding.
5. Part 4, external stylesheet, the best practice. Step 1: create styles.css in the same folder as the HTML. Step 2: move all the rules from the style element into styles.css. Step 3: replace the style element in the head with a link element. Fill-in: the link element needs rel="stylesheet" and href="styles.css".
6. Part 5, colors. Update styles.css with a custom palette: body background #f5f5f5 (light gray); h1 color #1a73e8 (a Google blue); p color #202124 (dark gray); .highlight with background #fff3cd (light yellow) and text #856404 (dark brown); the footer with background #202124 and white text. Fill-in: write the body background in RGB form as rgb(245, 245, 245), which is the same light gray.
7. Part 6, fonts. Add a Google Fonts link for Roboto (weights 400 and 700) in the head, before the styles.css link. In styles.css set font-family: 'Roboto', sans-serif on body, h1, and p; give h1 font-weight 700; give the footer font-size 14px. Fill-in: change the h1 font-size to anything larger than 32px, such as 40px or 48px.
8. Part 7, text properties. The complete stylesheet adds line-height 1.6 on body and p for easier reading, centers the h1 with text-align: center and increases it to 40px, and adds spacing and accents: margin-bottom on h1 and p, padding of 10px and a 4px solid yellow left border on .highlight, and margin-top 40px plus a 1px top border on the footer. Fill-in: an a (link) rule with color #1a73e8 and text-decoration: none to remove link underlines.
9. Part 8, final structure. You end with two files: practice.html (structure only, linked to styles.css, no inline styles) and styles.css (all rules, using element, class, and ID selectors, colors, fonts, and text properties). Separating HTML and CSS makes code easier to read, easier to update, reusable across pages, and professional.
10. Recap of the three methods. Inline: quick and immediate but not reusable and messy; for quick tests only. Internal: organized in one file but works for only one page; for single small projects. External: clean, reusable, and professional, though it is a separate file to manage; best for real websites.
11. Key takeaways: a rule is selector, then property: value; inside braces. Selectors are element, class, and ID. Common properties are color, font-family, font-size, font-weight, text-align, and line-height. Colors can be named, hex (#RRGGBB), or rgb(R, G, B). Google Fonts are linked in the head and used in font-family. Use external stylesheets. Next, you restyle your About Me page.

Key terms:
inline style — CSS in a style attribute on one tag.
internal stylesheet — CSS in a style element in the head.
external stylesheet — CSS in a separate file linked with the link element.
link element — written <link rel="stylesheet" href="styles.css">; connects the HTML page to the CSS file.
rel — link attribute saying what the linked file is (stylesheet).
href — link attribute giving the file path.
class selector (.highlight) and ID selector (hash sign plus footer) — target a class or one unique element.
background-color — the fill color behind an element.
hex color — a hash sign and six characters, such as #1a73e8.
rgb() — a color written as red, green, blue amounts from 0 to 255.
font-family, font-size, font-weight — typeface, size, boldness.
line-height — space between lines of text.
text-align — horizontal alignment.
text-decoration — adds or removes underlines; none removes them.
padding — space inside an element, between content and its edge.
margin (margin-bottom, margin-top) — space outside an element.
border (border-left, border-top) — a line around or along one side of an element, given as width, style, and color.

What you are asked to do:
- Build practice.html and follow Parts 1 through 7, filling in every blank as described above.
- End with practice.html linked to a styles.css containing all the rules and no inline styles.

Watch out for:
- The walkthrough places the Google Fonts link before your own stylesheet link in the head; copy that order.
- Remove the style element when you switch to the link element, so the rules live in only one place.
- Correction: Part 5's colors go in styles.css, the one stylesheet linked from practice.html. The code comment at the top of Part 5 says colors.css, but no such file is created or linked, so do not make one.
- Heads up: Parts 3 and 7 use padding, margin, and border without explaining them; for now, padding is space inside an element, margin is space outside it, and border is the line between them. The html06 box model lesson covers them fully.
