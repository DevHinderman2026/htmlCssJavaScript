Overview of: html01 Document Structure
Course: HTML CSS JavaScript track

What this lesson is about:
This is the first real HTML lesson. It explains that HTML (HyperText Markup Language) gives a page its structure and content, while CSS handles style and JavaScript handles interactivity. You learn the required skeleton of every HTML5 page: the doctype line, the html root element with a lang attribute, a head containing the meta charset tag and a title, and a body holding the visible content. You then add content with headings h1 through h6, paragraphs, line breaks, and hidden developer comments, and learn that browsers collapse extra whitespace. The lesson also sets up VS Code with Live Server for previewing pages. You leave able to type a valid page from memory and build a personal About Me page. Sub-lesson 01a is document structure and 01b is content markup.

1. html01 Slides summary.txt — the lesson slideshow: what HTML is, the skeleton, headings, paragraphs, comments, whitespace, VS Code setup.

5. html01b Task summary.txt — starter file with eight TODOs to add headings, paragraphs, a br, and a comment (My Skills page).
