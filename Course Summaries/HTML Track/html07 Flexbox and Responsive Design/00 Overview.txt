Overview of: html07 Flexbox and Responsive Design
Course: HTML CSS JavaScript track

What this lesson is about:
This lesson teaches modern CSS layout and how to make pages work on any screen size. Flexbox lines items up along one direction, a row or a column, with the container controlling spacing along that line (justify-content) and across it (align-items), wrapping (flex-wrap), and gaps (gap). Responsive design is taught mobile-first: write one-column phone styles as the default, then add min-width media queries at 768 pixels for tablets and 1024 pixels for desktops. Every page needs the viewport meta tag, and images need max-width 100 percent and height auto to scale without distortion. CSS Grid is introduced as the two-dimensional system that controls rows and columns at once; on exams it is recognition level only, with the fuller toolkit (repeat, minmax, auto-fit, spanning) left to the extension. You leave able to build a flexbox navigation bar and card row, a responsive blog layout, a grid page layout, and a photo gallery that goes from one to three columns.
