Overview of: html02 Semantic HTML
Course: HTML CSS JavaScript track

What this lesson is about:
This lesson teaches semantic HTML: choosing tags for what content means rather than how it looks. You learn to use strong and em instead of the purely visual b and i. You learn the page-region elements header, nav, main, section, article, aside, and footer, which give screen reader users landmarks to jump between and help search engines understand a page. Sub-lesson 02b covers the four list types: ordered lists (ol) for steps, unordered lists (ul) for items in no particular order, nested lists placed inside a list item, and description lists (dl with dt and dd) for term and value pairs. The main project is a recipe page, first guided and then on your own, checked with the W3C validator. You leave able to structure a whole page semantically and pick the right list for any content.
