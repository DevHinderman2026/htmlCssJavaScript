Course: HTML CSS JavaScript track
Lesson: html02 Semantic HTML
Type of document: task starter file

In one sentence:
This starter file is an "Ultimate Party Planning Guide" page where you add the four list types: an ordered list, an unordered list, an ordered list with nested lists, and a description list.

Main ideas:
The page is already built around the lists: title "Party Planning Guide"; a header with the h1 "Ultimate Party Planning Guide" and the tagline "Step-by-step instructions and checklists for a perfect event"; a main containing one section with the h2 "Planning Your Party"; and a footer with "copyright 2024 Party Planning Guide". Inside the section, four h3 headings are already in place (Timeline, Guest Essentials, Food Preparation, Party Supplies Checklist). Each has a TODO telling you which list to build under it and exactly what items to include. The lesson is picking the right list for the job: ol when order matters, ul when it does not, nested lists for sub-steps, and dl for name-and-detail pairs.

Key terms:
ol — ordered, numbered list for steps where order matters.
ul — unordered, bulleted list.
li — list item.
Nested list — a ul placed inside an li of the ol.
dl — description list.
dt — the term (such as Plates).
dd — the description (such as the amount per guest).

What you are asked to do:
1. Under Timeline, add an ol with these five steps: choose a date and venue (4 to 6 weeks before); create and send invitations (3 weeks before); plan the menu and purchase ingredients (1 week before); decorate and set up (1 day before); enjoy the party (day of event).
2. Under Guest Essentials, add a ul with: comfortable seating, good lighting, beverage station, music or entertainment, clean restrooms.
3. Under Food Preparation, add an ol with nested ul lists: 1, prepare appetizers, with sub-items arrange on platters and chill until serving; 2, cook main dishes, with sub-items set oven temperature and monitor cooking times; 3, prepare desserts, with sub-items bake ahead if possible and keep refrigerated; 4, set up the drink station (no sub-items).
Code: <li>Prepare appetizers <ul><li>Arrange on platters</li></ul></li>
This shows an outer list item that contains its own small bulleted list before the outer item closes.
4. Under Party Supplies Checklist, add a dl with these term and description pairs: Plates, paper or ceramic, 1 per guest plus extras; Cups, 2 to 3 per guest for multiple drinks; Napkins, 4 to 5 per guest; Utensils, forks, spoons, and knives for each guest; Trash bags, 3 to 4 large bags for cleanup.
Challenge checklist at the end: use ol where order matters, ul where it does not, nest lists inside li tags, use dl for key-value pairs like supplies, and validate at validator.w3.org.

Watch out for:
- The nested ul must go inside the li, before its closing tag, not between two li elements.
- In the dl, each dt is followed by its dd; do not wrap them in li.
- Keep the existing h3 headings; add each list below its heading.

Connects to:
