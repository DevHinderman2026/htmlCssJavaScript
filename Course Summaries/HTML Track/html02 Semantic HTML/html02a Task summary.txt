Type of document: task starter file

In one sentence:
This starter file has you build a "Brew Haven Coffee Shop" menu page by adding header, nav, main, section, article, aside, and footer elements where TODO comments tell you to.

Main ideas:
The file already has the doctype, html with lang en, meta charset UTF-8, the viewport meta tag, and an empty title element. The body contains only TODO comments with blank lines under them. The comments are indented to show nesting: sections inside main, and articles inside sections. The practice point is choosing the right region element for each kind of content: section for a themed group (a category of drinks) and article for a self-contained item (one drink).

Key terms:
header — top region with the shop name and tagline.
nav — navigation links.
main — wraps all the main content.
section — a themed group, here a drink category.
article — a self-contained item, here one drink.
aside — side content, here seasonal favorites.
footer — closing region with copyright.
&copy; — entity that displays the copyright symbol.

What you are asked to do:
1. In the head, put "Coffee Shop Menu" in the title tag. (The TODO says add a title tag, but an empty one is already there; fill it in.)
2. Add a header containing an h1 "Brew Haven Coffee Shop" and a p "Specialty Espresso Drinks".
3. Add a nav with links to Home, Menu, Hours, and Contact, written as anchor tags with a placeholder href of a number sign, separated by vertical bar characters.
Code: <a href="#">Home</a> |
This is one placeholder link followed by a separator bar.
4. Add a main element that wraps all the content below.
5. Inside main, add a section with the h2 "Classic Espresso Drinks" and the paragraph "Try our signature espresso-based beverages, expertly crafted with premium beans."
6. Inside that section, add three article elements, each with an h3 and a description: Espresso, "The perfect single or double shot of pure espresso."; Cappuccino, "Espresso topped with steamed milk and a layer of foam."; Latte, "Smooth espresso with steamed milk and a touch of foam."
7. Add a second section with the h2 "Specialty Drinks" and a description you write, containing an article for Caramel Macchiato: "Rich espresso, vanilla syrup, steamed milk, and whipped cream."
8. Add an aside with the h3 "Seasonal Favorites" and an unordered list of Pumpkin Spice Latte, Peppermint Mocha, and Salted Caramel Cold Brew.
9. Close the main element.
10. Add a footer with the copyright line "&copy; 2024 Brew Haven Coffee Shop".
Challenge checklist at the end: use the semantic elements header, nav, main, section, article, aside, and footer; close all tags; make sure the page validates at validator.w3.org.

Watch out for:
- Articles go inside their section; the aside goes inside main, before main closes.
- Close each article and section before starting the next.
- Only one title element in the head; fill in the existing one rather than adding a second.
