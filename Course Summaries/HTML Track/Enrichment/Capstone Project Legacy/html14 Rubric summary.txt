In one sentence:
This is the grading rubric for the html14 capstone website, with 7 categories and 27 criteria, each judged on five quality levels, for a total score out of 100.

Main ideas:
1. Every criterion is rated at one of five levels: Excellent, Good, Satisfactory, Needs Work, or Missing.
2. The total score is written as a blank out of 100.
3. Heads up: the rubric states only the 100-point total and gives no point value for any category or criterion, so the split is unknown. Aim for Excellent on every criterion, and check with Mr. McMaster if you need to know how the 100 points are divided.
4. Grade scale: 90 to 100 is an A, 80 to 89 is a B, 70 to 79 is a C, 60 to 69 is a D, below 60 is an F.
5. Each category is tied to an Ohio (ODE) Strand 6 outcome, listed with the category below.
6. Below, each criterion is given with what Excellent requires, then how the lower levels fall off.

Key terms:
Quality band or level — one of the five ratings (Excellent, Good, Satisfactory, Needs Work, Missing).
og tags — Open Graph meta tags that control how a page looks when shared on social media.
srcset — an image attribute that offers several image sizes so the browser can choose one.
WCAG AA — the accessibility level the contrast requirement is measured against.
Lighthouse — the DevTools audit scoring Performance, Accessibility, Best Practices, and SEO.
W3C validation — checking HTML and CSS with the official validators.

What you are asked to do:
Category 1, HTML Structure and Semantic Markup (Strand 6.1, write valid semantic HTML5):
1. Valid HTML and Boilerplate. Excellent: all 4 pages are valid HTML5 with DOCTYPE, html tags, and a head with charset and viewport meta tags. Lower levels: minor issues, then missing meta tags or inconsistent boilerplate, then missing critical tags, then no files or broken structure.
2. Semantic Elements. Excellent: strong use of header, nav, main, article, section, aside, and footer, with one h1 per page and correct h2 and h3 nesting. Needs Work includes multiple h1 elements or skipped heading levels.
3. 4 or more Pages and Navigation. Excellent: 4 or more pages linked by a consistent, working menu on every page. Lower levels: minor visual inconsistencies, then some broken links, then fewer than 4 pages or broken navigation.
4. Meta Tags. Excellent: every page has a descriptive title under 60 characters, a meta description of 100 to 160 characters, and proper og tags for social sharing. Lower levels: some generic, missing, too short, or too long.
Category 2, CSS Styling and Design (Strand 6.2, consistent visual design with custom CSS):
5. External Stylesheet. Excellent: one external .css file linked to all pages, organized with comments. Lower levels add inline styles and disorganization.
6. Custom Styling. Excellent: extensive custom CSS with a professional color scheme, type hierarchy, spacing, layout, and a consistent brand. Needs Work is mostly browser defaults.
7. Color and Font Consistency. Excellent: 3 to 5 colors used consistently and 2 distinct Google Fonts (heading and body). Satisfactory is 2 to 3 colors with consistency issues.
8. Visual Design Quality. Excellent: polished, with good whitespace, alignment, and visual hierarchy, and easy to navigate. Needs Work is cluttered or hard to follow.
Category 3, Responsive Design (Strand 6.3, mobile-first responsive layouts):
9. Mobile Design. Excellent: under 600 pixels the site is single-column, readable, with properly sized buttons and optimized navigation.
10. Tablet Design. Excellent: smooth adaptation at 600 to 1024 pixels, using two columns where it makes sense.
11. Desktop Design. Excellent: at 1024 pixels and up, multi-column where appropriate and professional use of space.
12. Media Queries or Framework. Excellent: media queries for all breakpoints using a mobile-first approach, or professional use of the Bootstrap grid, plus responsive images using srcset or the picture element. Satisfactory covers only 1 to 2 breakpoints; Needs Work has static image sizes.
13. Navigation Adaptation. Excellent: the menu adapts smoothly to mobile (hamburger or stacked) and is usable at every size. Missing means the navigation is the same at all sizes or broken.
Category 4, JavaScript and Forms (Strand 6.4, form validation and interactivity):
14. Form and Input Fields. Excellent: a contact form with 3 or more fields, proper input types (text, email, tel, textarea), and clear labels.
15. Form Validation. Excellent: required fields checked, email format validated, at least one custom rule (such as phone format or length), with clear error messages. Satisfactory checks only required fields and email.
16. JavaScript Functionality. Excellent: the JS file is linked, validation works smoothly, errors are clear, invalid submission is prevented, and a success message appears.
17. Interactivity Beyond Form. Excellent: 2 or more extra features (smooth scrolling, toggle menu, gallery, modal, animations, dynamic content). Good is 1 to 2, Satisfactory is 1 possibly with minor bugs.
Category 5, Content and Media (Strands 6.1 and 6.2):
18. Table. Excellent: meaningful data with 4 or more columns and 5 or more rows, clear headers, and styling such as borders and alternating rows. Good is 3 to 4 columns and 4 or more rows.
19. Images. Excellent: 4 or more optimized images, all with descriptive alt text, good quality and file size. Good is 3 to 4; Satisfactory is 3 with most having alt text; Needs Work is 2 to 3 with some alt text missing.
20. Meaningful Content. Excellent: original, well-written content that fits the theme, with no Lorem Ipsum. Missing means heavy Lorem Ipsum or unrelated content.
Category 6, SEO and Accessibility (Strand 6.5):
21. SEO Basics. Excellent: all 4 pages have unique, descriptive titles under 60 characters, meta descriptions of 100 to 160 characters, and correct heading order.
22. Accessibility. Excellent: WCAG AA contrast, descriptive alt text on all images, correct headings, full keyboard navigation with Tab, and no accessibility warnings.
23. Lighthouse Audit Score. Excellent: 80 or more in all four categories (Performance, Accessibility, Best Practices, SEO). Good: 75 to 79 on most, with one below 75. Satisfactory: 70 to 74 on most. Needs Work: 60 to 69. Missing: below 60.
Category 7, Deployment and Testing (Strand 6.5, deploy and test across browsers):
24. W3C Validation. Excellent: HTML and CSS pass with 0 errors, clean code. Good: 0 errors on all pages. Satisfactory: 1 to 2 errors that do not affect function. Needs Work: 3 to 5 errors. Missing: 5 or more errors or will not validate.
25. GitHub Pages Deployment. Excellent: live on GitHub Pages, public repo with a descriptive name, all files committed, and a README.md with description and link. Missing means not deployed or the repo is private.
26. Cross-Browser Testing. Excellent: tested in 3 or more browsers with identical look and behavior. Good: 2 browsers, same in both.
27. Link Testing and Polish. Excellent: all links work (no 404s), forms work, no console errors, professional finish.
Criteria count by category: 4, 4, 5, 4, 3, 3, and 4, for 27 criteria in all.

Teacher notes section: student names, strengths, areas for improvement, overall feedback.

Common deductions (the rubric just says "noted" and gives no point amounts): missing semantic tags; broken links or navigation; form validation not working; not responsive on mobile; missing alt text; HTML or CSS validation errors (noted per error); not deployed to GitHub Pages; missing README or planning template.

Extra credit opportunities (no point amounts given): Lighthouse accessibility score of 95 or more; advanced interactivity such as a multi-page image gallery, scroll animations, or a dark mode toggle; performance work such as optimized images, lazy loading, and minified CSS and JS; advanced CSS such as Grid, Flexbox mastery, and animations; a custom domain or deployment beyond GitHub Pages; advanced SEO such as structured data (schema.org), a sitemap.xml, or a robots.txt.

Watch out for:
- Excellent on Meta Tags requires og tags, which the Capstone Spec checklist never mentions.
- Excellent on Media Queries requires responsive images with srcset or the picture element.
- Multiple h1 elements or skipped heading levels drop you to Needs Work on Semantic Elements.
- Heads up: with no per-criterion point values, you cannot convert a level into points yourself; treat every level below Excellent as lost points.
- Correction: aim for 0 validation errors on every page, which both Excellent and Good require. The lower levels overlap (Needs Work is "3 to 5 errors" and Missing is "5 or more errors"), so exactly 5 errors is ambiguous and would be Mr. McMaster's call.
- Heads up: title tags and meta descriptions are graded twice, under Meta Tags in Category 1 and again under SEO Basics in Category 6, so a mistake there costs you in two places.
