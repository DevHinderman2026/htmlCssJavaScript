In one sentence:
This is the home page of the sample capstone site for a made-up coffee shop, Mountain View Coffee Co., showing a complete semantic page with head metadata, shared header and footer, and several content sections.

Main ideas:
1. The head section. It declares the language as English on the html element, sets the character encoding to UTF-8, and includes the viewport meta tag for phones. The title is "Mountain View Coffee Co. (separator bar) Premium Local Coffee." A meta description summarizes the shop (locally roasted coffee, pastries, cozy atmosphere). Three Open Graph tags (og:title, og:description, og:image) control how the page looks when shared on social media. The head links the external stylesheet html14_ExampleSolution_styles.css. Almost every part has an HTML comment explaining its purpose, so the file doubles as a lesson.
2. The header landmark. It holds the site name, "Mountain View Coffee Co.," as the page's h1 inside a logo container, and a nav element with class main-nav. Inside the nav is a hamburger button (id hamburger) made of three empty span elements that CSS draws as three lines, and an unordered list of four links (id navLinks): Home, About, Menu, Contact. The Home link has the class active to mark the current page.
3. The main landmark contains six sections, in order:
- Hero section: a wide placeholder photo (alt text "Coffee shop interior with warm lighting") with text over it: an h2 "Welcome to Mountain View Coffee Co.," a tagline, and a call-to-action link "Explore Our Menu" that goes to the menu page.
- Features section, h2 "Why Choose Mountain View?": three article cards in a grid, each with an image, an h3, and a paragraph: Locally Roasted, Community Hub, and Ethical Sourcing.
- Featured products section, h2 "This Week's Specials": three product boxes, each with image, h3 name, description, and a price paragraph (Ethiopian Yirgacheffe at 15.99 dollars per pound, Fresh Blueberry Muffins at 4.99 dollars each, Colombian Dark Roast at 16.99 dollars per pound).
- Testimonials section, h2 "What Our Customers Say": three blockquote elements, each holding a quote paragraph and a small footer element with the customer's name (Sarah M., James T., Emma L.).
- Call-to-action section, h2 "Ready for Your Perfect Cup?", with a "Get in Touch" link to the contact page.
4. The page footer landmark has three columns, each with an h3: the shop name with address and phone, Hours (Monday to Friday 6am to 6pm, Saturday 7am to 7pm, Sunday 8am to 5pm), and Follow Us with Facebook, Instagram, and Twitter links. A bottom strip holds a copyright line.
5. The script tag for html14_ExampleSolution_script.js is placed at the end of the body, so the page content loads before the JavaScript runs.
6. All images come from picsum.photos, a placeholder photo service, using a different random number for each image.

Key terms:
Open Graph tags — meta tags with property names like og:title that set the title, description, and image used when a link is shared on social media.
Hero section — the large banner area at the top of a home page.
Call to action (CTA) — a prominent link or button telling the visitor what to do next.
Blockquote (written <blockquote>) — an element for a quotation, used here for customer testimonials.
Active class — a class added to the current page's navigation link so it can be styled differently.
Landmark — a major page region (header, nav, main, footer) that screen readers let you jump between.

What you are asked to do:
Nothing directly; this is a model to study. Use it to see how a capstone home page organizes metadata, navigation, sections, headings, and the footer.

Watch out for:
- Every image has meaningful alt text, a good model to copy.
- Heading structure: the site name is the only h1 on this page, and each section starts with an h2, with h3 elements for cards. This is a clean outline for screen reader users.
- The hamburger button has no text and no aria-label, so a screen reader would announce it only as "button." When you build yours, give it a label such as aria-label="Menu" and consider aria-expanded.
- The social links point to fragment addresses like #facebook that do not exist on the page, so they are placeholders, not real links.
- The testimonial blockquotes use a footer element for the author name; this is valid HTML, but the shared stylesheet also styles every footer element, which affects how these look (see the styles summary).
