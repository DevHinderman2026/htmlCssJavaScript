Overview of: Exam Prep Sprint Legacy
Course: HTML CSS JavaScript track

What this lesson is about:
This is an older (legacy) exam preparation unit made of five short "sprints," each a condensed review of a topic on the web design certification exam. The first four sprints each have their own slides and study guide, and three of them add a hands-on task or activity. The fifth sprint is a whole-course review with a master study guide and a 40-question practice exam. On top of the sprints, the unit includes a team teaching project: four teams each write a follow-along markdown walkthrough on one sprint topic and teach it live to the class. A student leaves with a review of Bootstrap, forms, SEO, accessibility, deployment, troubleshooting, QA, and project management, plus practice explaining code clearly to others.

The five sprints (each has its own subfolder of summaries, written separately):
1. sprint01 Bootstrap — Bootstrap and responsive layouts: the CDN link, container, row, and column grid (12 columns), breakpoints, and components such as navbar, card, button, and alert, plus utility classes. Files: slides, study guide, and a task page.
2. sprint02 Forms — HTML forms and validation: GET versus POST, input types and labels, radio buttons versus checkboxes, dropdowns and textarea, fieldset and legend, submit and reset buttons, and basic form styling. Files: slides, study guide, and a task page.
3. sprint03 SEO and Deployment — SEO (titles, meta descriptions, heading order, alt text), accessibility (screen readers, ARIA labels, color contrast, legal requirements), web protocols (TCP/IP, HTTP, HTTPS, DNS, FTP), SSL certificates, static versus dynamic sites, and deploying with GitHub Pages. Files: slides, study guide, and a task page.
4. sprint04 Troubleshooting and QA — four troubleshooting methods (top-down, bottom-up, follow the path, spot the differences), quality assurance, writing test cases, usability testing and user acceptance testing, acceptance criteria, and project management (scope, stakeholders, target audience, design brief, milestones, critical path). Files: slides, study guide, and an activity worksheet.
5. sprint05 Exam Review — a final two-hour review of everything above plus business and ethics topics (intellectual property, ADA and WCAG levels, employability skills). Files: slides, a master study guide, and a 40-question practice exam with answer key.

Documents in this folder, in suggested order:
1. SPRINT WALKTHROUGH ASSIGNMENT summary.txt — the team teaching project: teams, topics, what each walkthrough must contain, topic guides, timeline, and the 100-point grading breakdown.
2. WALKTHROUGH TEMPLATE summary.txt — the fill-in skeleton each team uses to write its walkthrough file.
Then study the sprint subfolders in order, sprint01 through sprint05.

Other files in the original lesson:
The sprint01 Bootstrap source folder contains an images subfolder with 3 PNG images, each 300 by 200 pixels, named item-1, item-2, and item-3. No sprint01 file names them directly, but the sprint01 task asks students to build Bootstrap cards that each have a top image, so they are most likely the pictures for those cards. No other image or media files are in this unit, and no files at this top level were skipped.

Things to keep in mind:
- Only sprints 1 to 4 are assigned to teams; sprint 5 is the whole-class final review.
- The assignment refers to an html11 walkthrough file as a format example; it is not in the current html11 lesson but is in the Enrichment Bootstrap Basics folder, and html08 HTML Forms also has one.
- The current course's version of exam prep is html12 Exam Prep.
