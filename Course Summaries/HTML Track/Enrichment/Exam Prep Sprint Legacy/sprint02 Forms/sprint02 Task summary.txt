Summary of: sprint02_Task.html
Course: HTML CSS JavaScript track
Lesson: sprint02 Forms
Type of document: task starter file

In one sentence:
A starter page titled "Registration Form" where you follow ten TODO comments to build a complete registration form with three fieldsets, connected labels, radio buttons, checkboxes, and submit and reset buttons, in about 35 minutes.

Main ideas:
1. The page title is "Sprint 02 Task: Registration Form". The body has a white centered card (class container, max width 600 pixels) with a "Registration Form" heading and an instructions box that says to build a complete registration form in HTML by following the TODO comments, adding form controls, labels, fieldsets and buttons, with a time estimate of 35 minutes. A footer line at the bottom repeats "Estimated completion time: 35 minutes".
2. All the CSS is already written, so you only write HTML. The style block already handles:
- a purple gradient page background with the card centered using flexbox;
- fieldsets with a light border, padding and a light gray background, and bold legends;
- labels set to display block and semi-bold, so each sits on its own line above its field;
- text, email, password and tel inputs, selects and textareas set to full width with padding and rounded borders, and a colored border and soft glow on focus;
- a radio-group and checkbox-group class that keeps those labels inline with normal weight;
- a button-group class that lays buttons side by side with a gap;
- a purple submit button that lifts slightly on hover, and a gray reset button.
3. Because the CSS targets these exact elements and classes, using the right input types, fieldset, legend and the button-group div makes the page look finished.

Key terms:
fieldset and legend — group of related fields and its caption.
for and id — the pair that connects a label to its input.
required — attribute that stops submission if the field is empty.
placeholder — hint text inside an empty field.
type="tel" — input for a phone number.
radio-group and checkbox-group — class names the CSS already styles for option groups (optional to use).
button-group — class for the div holding the buttons.

What you are asked to do:
1. TODO 1: wrap everything in a form element with action="register.php" and method="POST".
2. TODO 2: create a fieldset with the legend "Personal Information".
3. TODO 3: add a text input for "First Name" with a label, using the for and id connection.
4. TODO 4: add a text input for "Last Name" with a label, using for and id.
5. TODO 5: add an email input with a label and the required attribute. (End of the Personal Information fieldset.)
6. TODO 6: create a second fieldset with the legend "Account Details".
7. TODO 7: add a password input with a label and the required attribute.
8. TODO 8: add a tel input for "Phone Number" with a label and a placeholder. (End of the Account Details fieldset.)
9. TODO 9: create a third fieldset with the legend "Preferences".
10. TODO 9a: add a label and radio buttons for preferred contact method, with options Email, Phone and Text Message, all using name="contactMethod".
11. TODO 9b: add checkboxes for interests, which can be multiple, with options Web Design, Programming and Graphic Design, each using name="interests". (End of the Preferences fieldset.)
12. TODO 10: add submit and reset buttons inside a div with class="button-group". (Then close the form.)
No point values or submission instructions are given in the file.

Watch out for:
- Each radio button and checkbox needs its own unique id and its own label, or screen readers will not announce the option names.
- All three radio buttons must share name="contactMethod" or they will not act as one group.
- The TODOs are indented to show nesting: the fieldsets go inside the form and the inputs go inside their fieldsets. Remember to close each fieldset and the form where the "End" comments are.
