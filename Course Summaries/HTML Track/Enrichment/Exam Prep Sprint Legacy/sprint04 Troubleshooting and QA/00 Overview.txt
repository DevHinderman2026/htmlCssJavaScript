Overview of: sprint04 Troubleshooting and QA
Course: HTML CSS JavaScript track

What this lesson is about:
This fourth legacy exam-prep sprint covers three professional skills tied to Ohio Outcomes 2.9, 2.11 and 2.12. For troubleshooting, you learn four systematic methods (Top-Down, Bottom-Up, Follow the Path, and Spot the Differences) and which symptom each one suits. For quality assurance, you learn how formal QA differs from random clicking, how to write a test case with an ID, steps, expected result, actual result and pass or fail, and how QA, usability testing and user acceptance testing differ. For project management, you learn scope and scope creep, stakeholders, target audience, the design brief, timelines, milestones, the critical path, and acceptance criteria. You leave able to answer "which method is best" exam questions and to plan and test a small client site.

Documents in this folder, in suggested order:
1. sprint04 Slides summary.txt — the slideshow: four troubleshooting methods, QA and test cases, usability and UAT, acceptance criteria, scope, design brief, milestones and critical path.
2. sprint04 StudyGuide summary.txt — 25 vocabulary terms, comparison table and decision guide, test case template, planning checklist, 5 common mistakes and 15 practice questions with answers.
3. sprint04 Activity summary.txt — a 45-minute worksheet: troubleshoot a missing navbar, write 5 test cases for a pizza order form, plan a dog grooming site, and write answers to 3 reflection questions (their text is left out of these notes).
