Overview of: sprint05 Exam Review
Course: HTML CSS JavaScript track

What this lesson is about:
This fifth and final legacy exam-prep sprint is a 2-hour review of everything in sprints 01 through 04, plus business and ethics topics that appear only here. It revisits the Bootstrap grid and breakpoints, form structure and GET versus POST, SEO and WCAG accessibility (including the POUR principles), web protocols and HTTPS, Git and GitHub Pages deployment, the four troubleshooting methods, and QA testing. It adds intellectual property (copyright, trademarks, fair use, Creative Commons licenses), ADA legal risk, WCAG levels A, AA and AAA, employability skills (portfolio, resume, professionalism), project phases and the design brief. A 40-question practice exam with an answer key lets you check readiness, with 70 percent (28 of 40) as passing. You leave with a single reference for final exam study.

Documents in this folder, in suggested order:
1. sprint05 Slides summary.txt — the review slideshow: quick hits on every topic and exam-day tips.
2. sprint05 MasterStudyGuide summary.txt — the complete study guide in seven sections, with every testable fact, the competency map and a top-ten list.
3. sprint05 PracticeExam summary.txt — all 40 practice questions with topic, correct answer and reason, plus scoring and exam tips.
