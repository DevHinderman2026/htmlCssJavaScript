In one sentence:
A 40-question multiple-choice practice exam covering all five sprints, with an answer key and explanations, a score guide, and exam tips.

Main ideas:
1. Rules: pick the BEST answer; some options are deliberately similar. Time limit is listed as 60 minutes (45 minutes actual exam time). Passing is 70 percent, which is 28 of 40.
2. The questions are grouped: Bootstrap and responsive design (1 to 6), HTML forms (7 to 12), SEO (13 to 17), accessibility (18 to 22), protocols and deployment (23 to 26), testing and deployment (27 to 30), troubleshooting methods (31 to 34), business, ethics and professional skills (35 to 40).
3. Score guide: 36 to 40 (90 to 100 percent) is excellent and ready; 32 to 35 (80 to 89 percent) is good, review weak areas; 28 to 31 (70 to 79 percent) is passing, focus on weak areas; below 28 means study more, review the Master Study Guide and retake the exam.

What you are asked to do:
Answer all 40 questions. Each is listed below with its topic, the correct answer, and the reason given in the key.

Bootstrap and responsive design:
1. Main purpose of the container. Answer b, to center and pad content with responsive margins. It is the basic wrapper that holds and centers content.
2. Width of col-md-6 on medium screens and up. Answer b, 50 percent of the row, because 6 of 12 columns is half; the number is not pixels.
3. Where the sm breakpoint begins. Answer a, 576 pixels. The others are md 768, lg 992, xl 1200, xxl 1400; below 576 is xs.
4. Which is NOT a Bootstrap component: navbar, card, framework, alert. Answer c, framework, because that is what Bootstrap is, not a part of it.
5. What m-3 does. Answer b, applies level 3 margin on a preset scale. The scale is m-0 none, m-1 0.25rem, m-2 0.5rem, m-3 1rem, m-4 1.5rem, m-5 3rem.
6. Hide content on mobile but show it on tablets and up. Answer a, d-none d-md-block, because d-none hides it and d-md-block overrides that from 768 pixels up. (The distractor hidden-xs is an old Bootstrap 3 class.)

HTML forms:
7. What action specifies. Answer b, the URL or script that receives the form data, such as process.php.
8. Main difference between GET and POST. Answer b, GET sends data in the URL, POST in the message body; GET is visible and bookmarkable, POST is hidden and allows more data.
9. Input for choosing only one option. Answer c, radio button; a select dropdown also allows one choice, but radio buttons are traditional for grouped options.
10. Purpose of fieldset and legend. Answer b, to group related controls and give the group a title.
11. Attribute a label needs to link to an input. Answer c, for, matching the input's id.
12. Best input for an email with built-in validation. Answer b, type="email". (type="mail" does not exist.)

SEO:
13. Ideal title length. Answer b, 50 to 60 characters, because Google shows about that many before cutting it off.
14. What the meta description controls. Answer c, the summary text under the title in search results, ideally 150 to 160 characters; Google may rewrite it.
15. How many h1 tags per page. Answer b, one, naming the main topic; several confuse screen readers and dilute SEO.
16. Why images need alt text. Answer c, to help screen readers and to show text when images do not load, which also helps SEO.
17. Most important SEO practice. Answer b, a unique, descriptive title and meta description; keyword stuffing and tricks break search guidelines.

Accessibility:
18. What ADA stands for. Answer b, Americans with Disabilities Act, the federal law requiring accessibility.
19. WCAG AA contrast for normal text. Answer c, 4.5 to 1; AAA requires 7 to 1.
20. Main purpose of ARIA. Answer b, to give extra semantic information to assistive technologies, especially for complex widgets like modals and custom dropdowns. (It does not replace semantic HTML.)
21. Which is NOT a common accessibility barrier. Answer c, using relative units like percentages, which actually help because they scale; missing alt text, missing labels and keyboard-inaccessible buttons are real barriers.
22. How a site should support users who cannot see. Answer b, provide alt text for images so it works with a screen reader; do not remove images or go text-only.

Protocols and deployment:
23. HTTPS's main security advantage. Answer c, it encrypts data in transit with SSL/TLS.
24. What DNS does. Answer b, converts domain names to IP addresses, like a phone book.
25. Where a Git commit stores changes. Answer b, in the local repository on your computer; git push is what sends it to GitHub.
26. URL format for a GitHub Pages project site. Answer b, username.github.io/project-name. A user site is just username.github.io, from a repository named that way.

Testing and deployment:
27. Purpose of the W3C HTML Validator. Answer b, to check that HTML follows the standards (validator.w3.org; there is also a CSS validator).
28. DevTools tab for network requests and response times. Answer c, the Network tab. Inspector shows HTML and CSS, Console shows errors and logs, Storage shows saved data.
29. Which should NOT be tested before publishing. Answer c, "the developer's personal favorites feature", because it is not a real feature; browsers, screen sizes and keyboard accessibility must all be tested.
30. What a 404 error means. Answer c, the requested file or page was not found, for example a broken link, a deleted page or a wrong file name.

Troubleshooting methods:
31. A JavaScript error is in the console and you need to find where it happens. Answer b, Bottom-Up: start from the error and trace back.
32. A form submits but data is not saved to the database. Answer c, Follow the Path: trace form, then handler, then database.
33. A button disappeared after you updated CSS. Answer d, Spot the Differences, using git diff to see what CSS changed.
34. A good use of browser breakpoints. Answer b, to pause JavaScript and inspect variables (in the Sources tab), not the Bootstrap screen-size breakpoints.

Business, ethics and professional skills:
35. Using a Getty Images photo. Answer b, check the license and either pay for it or use a Creative Commons image instead, because creative work is copyrighted by default. Cropping or removing a watermark does not make it legal.
36. Legal consequence of an inaccessible website. Answer c, lawsuits and settlements that can exceed 50,000 dollars; the key says settlements commonly run 35,000 to 50,000 dollars or more.
37. Best first step when a client has not defined what they want. Answer b, create a design brief documenting requirements, scope, timeline and stakeholders.
38. What scope includes. Answer b, what is included AND explicitly what is not; this prevents scope creep.
39. A manager asks you to put a client's database password in a shared Google Doc. Answer c, refuse; credentials must never go in shared documents or email. Have the person enter it themselves or use a secure credential manager.
40. Primary purpose of a portfolio. Answer a, to show your best work and abilities to potential employers; quality matters more than quantity.

Tips for the actual exam: read each question and all options twice; skip hard ones and return; eliminate obviously wrong answers; look for the words NOT and BEST because they change the question; trust what you learned across the five sprints; manage your time at about one minute per question.

Key terms:
d-none d-md-block — hidden on small screens, shown as a block from medium up.
rem — a CSS unit relative to the root font size, used in Bootstrap's spacing scale.
404 — HTTP status code meaning Not Found.
Network tab — DevTools panel listing requests, status codes, sizes and load times.
Sources tab — DevTools panel where JavaScript breakpoints are set.

Watch out for:
- Questions with NOT (4, 21, 29) ask for the wrong-one-out.
- Two meanings of "breakpoint": a Bootstrap screen width versus a JavaScript debugging pause (question 34).
- Correction: an input with type="email" brings up a keyboard with the at sign on phones, not a number pad (type="tel" or type="number" give a number pad). The explanation for question 12 gets this wrong, but answer b is still the right choice.
- Correction: the user, not the website, runs the screen reader; the website's job is to provide alt text that the screen reader reads aloud. Question 22's answer b is worded as if the site uses a screen reader, but b is still the one to pick.
- Heads up: the explanation for question 29 is garbled in the original (it begins "Wrong question."). The answer is c, because "the developer's personal favorites feature" is not a real feature, while browsers, screen sizes and keyboard accessibility all must be tested.
- Correction: the Certiport IT Specialist HTML and CSS exam (the certification the current html12 lesson prepares for) has 35 to 45 questions in 50 minutes and needs 70 percent to pass, so plan for about 50 minutes, a little over a minute per question. This practice exam's header says 60 minutes (45 minutes actual exam time) and its final tip says "60 questions in 60 minutes," which is wrong; this 40-question practice exam matches the real exam's size.
- Heads up: option d of question 9 gives away a hint in parentheses (that both radio buttons and a select work). Answer c, radio button, is still the one to pick for a grouped single choice.
- Correction: ADA website lawsuit settlements commonly run about 5,000 to 20,000 dollars (sometimes less for small businesses), while total costs with legal fees and site fixes can be much higher, and figures vary a lot by source. The key's claim that settlements commonly run 35,000 to 50,000 dollars or more is overstated, but answer c is still right: inaccessible sites create real legal and financial risk.
