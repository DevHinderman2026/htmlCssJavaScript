Overview of: sprint03 SEO and Deployment
Course: HTML CSS JavaScript track

What this lesson is about:
This third legacy exam-prep sprint covers search engine optimization, accessibility, web protocols and deployment. You learn how search engines crawl, index and rank pages, and how the title tag (50 to 60 characters), meta description (150 to 160 characters), a single h1 with no skipped heading levels, and descriptive alt text help both search engines and screen reader users. You learn the ADA and WCAG (Level AA as the target), the 4.5 to 1 contrast minimum, aria-label for icon buttons, and why real button elements beat clickable divs. You learn the protocols TCP/IP, DNS, HTTP, HTTPS, FTP and SFTP with their port numbers, what an SSL certificate does, and the difference between static and dynamic sites. Finally you learn the Git steps to publish a static site on GitHub Pages. The big idea is that SEO and accessibility use the same practices: clear, semantic structure.

Documents in this folder, in suggested order:
1. sprint03 Slides summary.txt — the slideshow: SEO, title and meta description, headings and alt text, accessibility, protocols, HTTPS, static versus dynamic, GitHub Pages.

3. sprint03 Task summary.txt — a broken bakery page with 10 TODOs to fix SEO and accessibility, then deploy to GitHub Pages.
