In one sentence:
This study guide collects the Bootstrap vocabulary, a class cheat sheet, the state competencies covered, key concepts, common mistakes, and ten study questions with answers.

Main ideas:
1. Vocabulary. The guide defines 26 terms, from Bootstrap and framework through the grid classes, the breakpoints, the components, and the utility classes. All are listed under Key terms below.
2. Grid cheat sheet. The structure is always a container, then a row inside it, then columns inside the row. A plain col takes an automatic equal width. col-12 is full width on mobile. col-md-6 is half width at medium screens. col-lg-4 is about one third at large screens.
3. Breakpoint reference. The default size, xs, has no class infix and covers screens under 576 pixels. Then: Small uses col-sm-something from 576 pixels; Medium uses col-md-something from 768; Large uses col-lg-something from 992; Extra Large uses col-xl-something from 1200; 2XL uses col-xxl-something from 1400. The "something" is a number of columns out of 12.
4. Component cheat sheet. Navbar: a nav element with classes navbar navbar-expand-lg navbar-dark bg-dark, and a brand link with class navbar-brand. Card: a div with class card holding card-body, which holds a card-title heading and card-text paragraph. Buttons: btn plus btn-primary or btn-success. Alert: a div with classes alert alert-info. Form input: an input with class form-control.
5. Utility cheat sheet. Spacing uses m for margin and p for padding with a scale of 1 to 5, such as m-3 or p-2. The class mx-auto sets automatic left and right margins, which centers a block horizontally. Text alignment: text-center, text-start (left), text-end (right). Colors: bg-primary with text-white gives a blue background with white text; text-success is green text; text-danger is red text. Display: d-none hides an element; d-block makes it display as a block.
6. Ohio (ODE) competencies addressed. 6.5.3 Standard Web Languages: Bootstrap as an extension of HTML and CSS, styling with classes instead of custom CSS. 6.5.6 Create and Edit Web Page Templates: responsive layouts with the grid, using components to structure pages, reusable component patterns. 6.5.13 Responsive Design: applying breakpoints for mobile-first layouts, responsive column sizing, testing at different screen sizes. 6.1.7 Integrate External CSS and Resources: loading Bootstrap CSS by CDN in the head and using the external JavaScript bundle for interactive components.
7. Why Bootstrap. Speed (pre-built components save hours), consistency (a professional look), responsiveness (mobile-first), and community (many plugins and examples).
8. The 12-column grid. Bootstrap divides the screen width into 12 equal parts, and you say how many parts each element takes at each breakpoint. The example is three cards each with col-12 col-md-6 col-lg-4: one per row on phones, two per row on tablets, three per row on desktops.
9. Mobile-first thinking. The default classes describe the phone layout; you then add breakpoint classes to change the layout on larger screens.

Key terms:
Bootstrap — a front-end framework providing CSS and JavaScript for responsive design.
Framework — a pre-built collection of tools, styles, and components.
CDN — Content Delivery Network; loading libraries from the web instead of local files.
Container — a class (container or container-fluid) that holds content and sets a max width.
Container-fluid — a container that spans 100 percent of the screen width.
Row — a horizontal line in the grid that contains columns.
Col — a column in the grid that divides horizontal space.
Grid System — Bootstrap's 12-column layout, container then row then col.
Breakpoint — a screen size where layouts change: xs, sm, md, lg, xl, xxl.
Responsive Design — a layout that adapts to different screen sizes and devices.
sm — small screens, 576 pixels and up.
md — medium screens, 768 pixels and up.
lg — large screens, 992 pixels and up.
xl — extra-large screens, 1200 pixels and up.
xxl — 2XL screens, 1400 pixels and up.
Navbar — Bootstrap's navigation bar component at the top of a page.
Card — a container component for a title, text, and images.
Card-body — the inner content area of a card.
Card-title — a heading inside a card.
Button — a component for user actions (btn, btn-primary, btn-success, and so on).
Alert — a message component (alert-info, alert-warning, alert-success, alert-danger).
Form-control — a class that styles form inputs such as text, email, and textarea.
Utility Class — a class that applies one single style, such as spacing, color, or alignment.
Margin — space outside an element; controlled by m- classes.
Padding — space inside an element; controlled by p- classes.
Text-center — a utility that centers text horizontally.
mx-auto — automatic horizontal margins, used to center a block.
text-start, text-end — left and right text alignment.
text-danger — red text color.
d-none, d-block — hide an element, or display it as a block.

What you are asked to do:
Study questions, with the answers the guide gives:
1. What three things are needed to use Bootstrap in an HTML file? Answer: the Bootstrap CSS CDN link, the Bootstrap JS CDN link, and the container, row, col structure.
2. How many columns does Bootstrap's grid have? Answer: 12.
3. Which breakpoint applies to screens 768 pixels and wider? Answer: medium, md.
4. What is the difference between container and container-fluid? Answer: container has a max width; container-fluid is 100 percent width.
5. How would you make a column full width on mobile but 50 percent on tablets? Answer: class="col-12 col-md-6".
6. What component is used for a navigation bar? Answer: navbar.
7. What class centers text? Answer: text-center.
8. How would you add margin to all sides of an element? Answer: m-1 through m-5.
9. Name three Bootstrap color utility classes. Answer: for example bg-primary, text-success, bg-danger.
10. What does CDN stand for? Answer: Content Delivery Network.

Watch out for:
The guide's list of common mistakes:
1. Forgetting the container or container-fluid wrapper; the grid does not work without it.
2. Using columns without a row; columns must be inside rows.
3. Forgetting the CDN link; then nothing gets Bootstrap styling.
4. Overriding Bootstrap with custom CSS; use utilities first and custom CSS only when needed.
5. Not testing responsiveness; always resize the browser to test the breakpoints.
Correction: container, row and col are class names used on div elements, not HTML tags, for example a div with class="container". The guide writes the first two mistakes with angle brackets as if they were tags.
