What this lesson is about:
Bootstrap Basics is the retired Lesson 11 unit on Bootstrap 5, a popular front-end framework that lets you style and lay out pages by adding ready-made class names instead of writing your own CSS. It is no longer on the graded path. It stays in the course for two reasons: it is the "component menu" for the html11c AI build, where you name Bootstrap parts when directing an AI, and it is extra enrichment for fast finishers. Sub-lesson 11a covers loading Bootstrap from a CDN and the 12-column grid of containers, rows, and columns with responsive breakpoints (sm, md, lg, xl, xxl). Sub-lesson 11b covers components (navbar, cards, buttons, alerts, forms) and utility classes for spacing, text alignment, color, and display. You leave able to read Bootstrap markup, name its components, and build a responsive landing page that stacks on phones and spreads into columns on wider screens.

Documents in this folder, in suggested order:
1. html11 Slides summary.txt — the slideshow introducing Bootstrap, the grid, breakpoints, components, and utilities.
2. html11 StudyGuide summary.txt — vocabulary, class cheat sheet, competencies, common mistakes, and ten study questions with answers.
3. html11 Walkthrough summary.txt — guided build of a Bootstrap landing page with a navbar, hero, card grid, alert, form, and footer.
4. html11a Task summary.txt — starter file: build a four-item responsive grid.
5. html11b Task summary.txt — starter file: build a page from Bootstrap components.
6. html11 DIYTask summary.txt — independent project: a responsive business landing page with a 14-item grading checklist.
