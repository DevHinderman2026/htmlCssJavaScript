Type of document: README

In one sentence:
This short README explains that everything in the enrichment folder is optional, not graded, and says what each subfolder is and where parts of it were reused.

Main ideas:
1. Nothing in the enrichment folder is on the graded path of the course.
2. bootstrapBasics is the retired Bootstrap unit. It is still used as the component menu for the html11c AI build, and it is available as enrichment for fast finishers.
3. examPrep_sprint_legacy is last year's catch-up sprint series. Sprint 04's troubleshooting activity and Sprint 05's study guide and practice exam were reused in html12 Exam Prep, with the Bootstrap content removed. The rest of the sprint series is retired.
4. capstoneProject_legacy is the old html14 capstone project. Its planning template and rubric were reused in html11 Build It Three Ways.
5. It also lists two folders, jsDom_leftovers and publish_leftovers, described as empty leftovers from a folder migration that are safe to delete by hand.

Key terms:
Enrichment — optional extra material beyond the graded course.
Legacy — older material kept for reference that has been replaced.
Capstone — a final, culminating project.

Watch out for:
- Legacy material may not match the current course. For example, current exam prep had Bootstrap removed, so do not assume Bootstrap is on the exam just because the old sprint covers it.
Heads up: the jsDom_leftovers and publish_leftovers folders the README mentions are not in the enrichment folder; they appear to have been deleted already, so there is nothing to look for or clean up.

Connects to:
html11 Build It Three Ways (reuses the capstone planning template and the Bootstrap component menu) and html12 Exam Prep (reuses parts of the sprint series).
