Overview of: html12 Exam Prep
Course: HTML CSS JavaScript track

What this lesson is about:
This is the final unit of the course, about eight class days of review before the end-of-course exams in mid-December. Everyone follows Lane 1, which prepares for the WebXam state exam through mixed review, troubleshooting scenarios, a full study guide, and a timed 40-question practice exam. Students who opt in also follow Lane 2, an ungraded lane for the Certiport ITS HTML and CSS certification, which focuses on precise CSS rules like specificity, the cascade, inheritance and units, plus certification-only topics like image maps and character entities. The review covers responsive design, HTML forms, SEO and accessibility, protocols and GitHub Pages publishing, the four troubleshooting methods and QA testing, and business topics such as copyright, the ADA, WCAG levels, and project management. You leave with a complete fact list for the exam and a study habit, the distractor autopsy, for learning from wrong answers.

Documents in this folder, in suggested order:
1. html12 UnitGuide summary.txt — the day-by-day plan for both lanes and which materials to use when.
2. html12 MasterStudyGuide summary.txt — every testable fact for the final exam, organized in seven sections.
3. html12 TroubleshootingScenarios summary.txt — worksheet scenarios on spot-the-differences troubleshooting, writing test cases, and project planning, with the ideas they test (unanswered prompts left out).
4. html12 PracticeExam summary.txt — all 40 practice questions with the correct answer and a short reason for each.
5. html12 CertLane CheatCard summary.txt — one-page list of the most-missed Certiport facts for exam morning.
6. html12 CertLane DistractorAutopsy summary.txt — the method of explaining why each wrong answer is wrong, with a worked example.

Other files in the original lesson:
The folder contains only these six Markdown files; there are no images, media or other non-text files. The unit guide refers to materials kept elsewhere that are not in this folder: the Certiport HTML and CSS study guide with its mock quiz, the course master plan's coverage table, and the Gimkit question files from earlier units.
