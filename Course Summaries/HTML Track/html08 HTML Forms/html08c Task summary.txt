In one sentence:
This starter page gives you a finished but unstyled event registration form, and TODO comments in the style block tell you exactly which CSS to write to make it look professional.

Main ideas:
This is sub-lesson 08c, Form Styling. Here the HTML is done and your job is only the CSS: page layout, the form card, fieldsets, legends, labels, fields, focus states, buttons and hover states.

What the starter page already contains (the HTML):
- Title "Form Styling Task" and an h1 reading "Event Registration Form".
- A form with action="/register-event" and method="POST".
- Fieldset "Personal Information": First Name (text, placeholder John, required), Last Name (text, placeholder Smith, required), Email (email, placeholder john@example.com, required), and Phone (tel, placeholder (555) 123-4567). Each has a label connected with for and id.
- Fieldset "Event Details": Preferred Date (date, required); Event Type, a select with a "-- Select --" placeholder option and the choices Workshop, Conference, Webinar and Meetup; and Additional Comments, a textarea with 4 rows, 50 cols and the placeholder "Tell us about yourself...".
- A div with class button-group holding a submit button "Register" and a reset button "Clear".
- An internal style block that contains only TODO comments.

Key terms:
box-shadow — adds a soft shadow around a box.
border-radius — rounds the corners.
box-sizing: border-box — width includes padding and border, so a 100 percent wide field does not overflow.
:focus — styles the field currently being used.
:hover — styles a button while the mouse is over it.
transition — makes a style change animate smoothly.

What you are asked to do:
Write CSS for each TODO:
1. body: max-width 600px, center with margin auto, padding 20px, background-color #f5f5f5 (very light gray).
2. h1: color #333 (dark gray), text-align center.
3. form: white background, padding 25px, border-radius 8px, box-shadow 0 2px 8px rgba(0,0,0,0.1), meaning a faint shadow just below the box.
4. fieldset: border 1px solid #ddd (light gray), padding 15px, margin 15px 0, background-color #fafafa, border-radius 5px.
5. legend: bold, font-size 1.05em, color #333.
6. label: display block, margin-top 10px, margin-bottom 5px, bold, color #333.
7. Text inputs, email inputs, textarea and select: width 100%, padding 10px, margin-bottom 15px, border 1px solid #ccc, border-radius 4px, font-size 16px, box-sizing border-box.
8. Input focus state: outline none, border-color #007bff (blue), box-shadow 0 0 5px rgba(0, 123, 255, 0.3), meaning a soft blue glow.
9. button: padding 12px 20px, background-color #007bff, white text, border none, border-radius 4px, font-size 16px, bold, cursor pointer, transition background-color 0.3s ease.
10. button:hover: background-color #0056b3 (darker blue).
11. The button-group div (selector .button-group): text-align center, margin-top 20px.
Code: input:focus { outline: none; border-color: #007bff; }
This removes the browser's default focus ring and replaces it with a blue border when a field is active.

Watch out for:
- Target the button group with a class selector, a period followed by button-group.
- The TODO for field styles mentions text and email inputs, textarea and select, but the form also has tel and date inputs; decide whether to include them so all fields match.
- Removing the outline is only acceptable because the task replaces it with a visible border and glow; never remove focus styling without a replacement.
- Both buttons get the same blue style here; nothing makes Clear look different from Register.
