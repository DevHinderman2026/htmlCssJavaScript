Overview of: html08 HTML Forms
Course: HTML CSS JavaScript track

What this lesson is about:
This lesson teaches how web pages collect information from people using HTML forms. You learn the form element and its action and method attributes, including the difference between sending data with GET and with POST. You learn the main controls: text, email, password, number, date, tel and url inputs, radio buttons for one choice, checkboxes for many, select dropdowns, and multi-line textareas. You learn to connect every control to a label using for and id, and to group related controls with fieldset and legend, which is what makes a form usable with a screen reader. You also learn submit and reset buttons, tabindex, and how to style forms with CSS, including focus and hover states and a mobile media query. By the end you can build and style a complete, accessible, multi-section survey form.
