In one sentence:
These slides introduce JavaScript basics for sub-lessons 09a (scripts and variables) and 09b (functions and operators), leading up to the Mad Libs project.

Main ideas:
1. What JavaScript does. It makes pages interactive and dynamic. It responds to user actions like clicks, typing, and scrolling, and it changes content, styles, and behavior while the page is open. It runs in the browser, which is called client-side. Examples given: form validation, animations, games, and Mad Libs generators.
2. The script tag. JavaScript goes into a page in one of two ways.
- Inline: code is written between an opening script tag and a closing script tag inside the HTML file. The example prints a hello message to the console.
- External: the code lives in its own file and is linked.
Code: <script src="script.js"></script>
This tells the browser to load and run the JavaScript file named script.js. The best practice is to use external scripts because they keep code organized and reusable.
3. console.log(), your debugging friend. It prints messages to the browser console. Examples: printing a text message; printing a label and a value separated by a comma (the label Age and the number 25); and printing a calculation, where console.log(3 + 5) prints 8. To see the console, press F12 and choose the Console tab. Use it to test code and find bugs.
4. Variables store data. There are three keywords.
- let is modern and block-scoped; use it for values that may change. Examples: let studentName = 'Alex'; and let score = 95;
- const makes a value that cannot be reassigned; use it for fixed values. Examples: const courseCode = 'WEB101'; and const PI = 3.14159;
- var is the old style; avoid it, but you will see it in older code.
Variable names use camelCase, like myFirstVariable or studentAge.
5. Data types.
- String: text inside quotes, either single or double, like 'blue' or "Hello World".
- Number: whole numbers or decimals, like 16 or 98.6.
- Boolean: only true or false, like isStudent = true.
- Undefined: a variable declared with no value yet, like let emptyVar; with nothing assigned.
- Null: a value deliberately set to "empty," like let noValue = null;
6. Functions are reusable blocks of code (start of sub-lesson 09b).
Code: function greetUser(name) { return 'Hello, ' + name + '!'; }
Step by step: this defines a function called greetUser with one parameter called name. When it runs, it joins the text Hello comma space, the name, and an exclamation mark, and returns that finished string. Calling greetUser('Maya') and storing the result in a variable called greeting, then logging it, prints Hello, Maya!
- A parameter (name) is what the function expects.
- An argument ('Maya') is the actual value you pass in.
- return sends data back to whoever called the function.
7. Operators and string concatenation. The plus sign adds (10 + 5 is 15), the minus sign subtracts (10 - 3 is 7), and the asterisk multiplies (4 times 6 is 24). With strings, the plus sign joins them: 'Hello ' + firstName + '!' makes Hello John! when firstName is John. A template literal does the same thing more cleanly: the text is written between backtick characters, and a variable is inserted by writing a dollar sign followed by the variable name inside curly braces. So backtick, Hello dollar-sign open-brace firstName close-brace exclamation mark, backtick, also gives Hello John!. Inserting a value this way is called interpolation.
8. Comments document your code. A single-line comment starts with two forward slashes. A multi-line comment starts with slash-star and ends with star-slash and can cover a whole section. Always explain why, not just what. Good example: let taxRate = 0.07; with the comment "Ohio sales tax is 7%". Bad example: let x = 5; with the comment "x is 5", which adds nothing. A better version names the variable studentCount and comments "Total students in first period."
9. Your first Mad Libs generator. The class will build a page that stores words in variables, uses a function to combine them into a story, and displays the funny result on the page. Next come walkthroughs, practice tasks, and then your own Mad Libs.
10. Wrap-up (the slide's review questions are left out of these notes). Key takeaway: JavaScript makes sites interactive, variables store data, functions organize code, and comments explain your thinking.

Key terms:
JavaScript — the programming language that runs in the browser to make pages interactive.
client-side — running in the user's browser.
script element (written <script>) — holds JavaScript or links to a .js file.
src attribute — on the script tag, the path to an external JavaScript file.
console.log() — prints to the browser console for testing.
variable — a named container for a value.
let — declares a variable whose value can change.
const — declares a variable that cannot be reassigned.
var — the old way to declare a variable; avoid.
block-scoped — a variable only exists inside the curly-brace block where it was made (let and const work this way).
camelCase — naming style like studentAge.
string, number, boolean, undefined, null — the five data types shown.
function — a reusable block of code.
parameter — the placeholder name a function expects.
argument — the actual value passed when calling a function.
return — sends a value back from a function.
operator — a symbol like plus, minus, or asterisk that does an operation.
concatenation — joining strings with the plus sign.
template literal — a backtick string that can insert values with dollar sign and curly braces.
interpolation — inserting a variable's value into a string.
comment — a note in code that the computer ignores.

Watch out for:
- Reassigning a const causes an error; use let if the value will change.
- Avoid var in new code.
- Comments should explain why, not repeat what the code obviously does.
- In the Unit Guide, concatenation with the plus sign is the tested form; template literals are only introduced here.
