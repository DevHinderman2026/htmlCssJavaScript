In one sentence:
This optional "Feature Menu" gives fast finishers four extra interactive features to add to their real site, all using the same select, listen, toggle, and CSS pattern.

Main ideas:
1. It is for fast finishers only, as extra credit with no points and no rubric. Finish the regular html09 tasks first.
2. Every item uses the same four moves you already know: select an element, listen for an event, toggle a class, and let CSS finish. Pick any; each one counts separately. Add them to your real site.
3. The menu:
- FAQ accordion: questions that expand and collapse when clicked. The document says the old html10 walkthrough's "Putting It All Together" section shows the pattern.
- Scroll-to-top button: appears after you scroll down; clicking it returns to the top. Hint: listen for the scroll event on window, and toggle a class that shows or hides the button.
- Image lightbox: click a thumbnail and a large version appears over the page; click anywhere to dismiss it.
- Tabs: three buttons and three content panels, with only one panel visible at a time. Hint: each click toggles classes on two things.

Key terms:
accordion — a list where clicking a question expands or collapses its answer.
scroll event — fires on the window as the page scrolls.
window — the JavaScript object for the browser window.
lightbox — a large image shown over the page, dismissed with a click.
tabs — buttons that each show one content panel and hide the others.
toggle — switch a class on or off.

What you are asked to do:
Choose any of the four features and add them to your site. Commit your updated site with each feature working, and write one sentence per feature in the commit message saying what you added.
Done when:
- Each chosen feature works by mouse and by keyboard.
- No feature broke dark mode or the hamburger menu; test both after each addition.
- Pushed to GitHub.

Watch out for:
- Keyboard support is required, so use real button elements for anything clickable.
- Retest dark mode and the hamburger after every new feature.
Heads up: the teacher materials named as the accordion reference are not in your folder, but the same FAQ accordion pattern is in Part 7 of html09_DomWalkthrough, which is. Use that (with this.nextElementSibling written as a property).
