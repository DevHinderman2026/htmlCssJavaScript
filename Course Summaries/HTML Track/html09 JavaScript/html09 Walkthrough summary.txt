In one sentence:
This eight-part guided walkthrough takes you from printing "Hello World!" in the console to writing functions and connecting JavaScript to an HTML page, with fill-in-the-blank "Try This" exercises in each part.

Main ideas:
1. Part 1, open the console and test console.log(). Press F12 (or right-click, choose Inspect, then the Console tab). Type console.log('Hello World!'); and press Enter; the console shows Hello World!. Try This: print your name, print a number, and print the result of adding two numbers.
2. Part 2, create variables. Three examples: a string, let myName = 'Alex'; (strings need quotes); a number, let myAge = 16; and a boolean, let isStudent = true; Logging each one prints Alex, 16, and true. Try This: make a variable named favoriteColor holding a color name as a string, make a variable named score holding a number, and print both with console.log().
3. Part 3, let versus const. Use let when a value might change. Example: let counter = 0; then counter = 5; works, and logging counter prints 5. Use const when a value should not change. Example: const courseCode = 'WEB101'; followed by courseCode = 'WEB102'; causes an error, because a const cannot be reassigned. Try This: make a const named schoolName for your school, and a let named gamePoints for something that changes.
4. Part 4, string concatenation, called the "old way."
Code: let greeting = 'Hello ' + firstName + '!';
In words: with firstName set to John, this joins the text Hello and a space, the name, and an exclamation mark, so greeting becomes Hello John!. Try This: make a variable name, build a greeting that starts with Welcome comma space, adds the name, and ends with an exclamation mark, then log it.
5. Part 5, template literals, called "modern and clean." The text goes between backtick characters, and each variable is inserted by writing a dollar sign and the variable name in curly braces. With firstName Maya, the greeting becomes Hello Maya!. A second example inserts both firstName Alex and lastName Johnson to print Hi, I'm Alex Johnson. Try This: make variables name and age and build the sentence "My name is (name) and I am (age) years old." then log it.
6. Part 6, your first function.
Code: function sayHello(name) {
In words: the keyword function starts the definition, sayHello is the function's name, and name in parentheses is its parameter. Inside the curly braces, return sends back a template literal that says Hello, the name, and an exclamation mark. Calling sayHello('Sarah') and storing it in result, then logging result, prints Hello, Sarah!. Calling it again with 'Marco' prints Hello, Marco!, showing reuse. Try This: finish a function named addNumbers with parameters num1 and num2 that returns their sum; addNumbers(5, 3) should print 8.
7. Part 7, connect JavaScript to an HTML page. You build a complete HTML5 page: a DOCTYPE, an html element with lang="en", a head with a UTF-8 charset meta tag, a viewport meta tag, and the title My First JavaScript. The body has an h1 reading JavaScript Test, a paragraph telling you to check the console with F12, and a script element at the bottom of the body. Step by step, the script:
- creates studentName set to 'YOU' and courseNumber set to 9;
- logs "Welcome to Lesson " joined with courseNumber using the plus sign, so it prints Welcome to Lesson 9;
- logs a template literal that says Your name is YOU;
- defines a function buildGreeting with parameters name and lesson that returns a sentence saying that name is learning JavaScript in that lesson;
- calls buildGreeting with studentName and courseNumber and logs the result.
Try This: save it as myFirstJS.html, open it in a browser, press F12 to view the console, change the variable values to see what prints, and edit the function to return a different sentence.
8. Part 8, add comments. Each line of the example is preceded by a comment explaining it: a comment that the variable stores the student's name, a comment that the function makeGreeting builds a friendly message, a comment inside the function that it uses a template literal, and a comment that the call prints the result. makeGreeting('John', 'Smith') returns Hi John Smith, welcome to web dev!. It also shows a multi-line comment, starting with slash-star and ending with star-slash, used for explaining bigger blocks.
9. Summary checklist: you learned to use console.log() to test code, create variables with let and const, recognize strings, numbers, and booleans, build strings with concatenation and template literals, write and call functions, add comments, and connect JavaScript to HTML. Next step: Tasks 09a and 09b.

Key terms:
console — the Developer Tools panel where console.log output appears (open with F12).
console.log() — prints a value to the console.
let — declares a variable that can be reassigned.
const — declares a variable that cannot be reassigned.
reassign — give an existing variable a new value with the equals sign.
concatenation — joining strings with the plus sign.
template literal — a backtick string with dollar-sign-and-curly-brace placeholders.
function — a named, reusable block of code.
parameter — the name a function uses for its input.
argument — the value you pass in when calling.
return — sends the result back from a function.
script element (written <script>) — where JavaScript goes in an HTML page.
comment — a note for humans; single-line starts with two slashes, multi-line is wrapped in slash-star and star-slash.

What you are asked to do:
Complete every Try This blank in Parts 1 through 7: print your name, a number, and a sum; create favoriteColor and score and print them; create const schoolName and let gamePoints; build a Welcome greeting with concatenation; build the "My name is ... and I am ... years old." sentence with a template literal; finish addNumbers so it returns num1 plus num2; and save, run, and modify myFirstJS.html.

Watch out for:
- Reassigning a const throws an error.
- Strings need quotes; numbers and booleans do not.
- Parts 1 to 6 assume the F12 console works. The Unit Guide warns it may be blocked on school machines; if so, use the say() output-div method from the Unit Guide instead.
Correction: a variable declared with let cannot be declared again in the same scope; doing so is a SyntaxError that stops the whole script. Part 5's example declares let firstName and let greeting twice, so run its two halves as separate scripts or rename the second set.
- The walkthrough uses template literals in many examples, but the Unit Guide says concatenation with the plus sign is the tested form.
