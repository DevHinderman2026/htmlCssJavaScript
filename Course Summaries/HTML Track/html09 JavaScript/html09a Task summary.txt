In one sentence:
This starter HTML page is Task 09a, variables practice: you fill in a script block following TODO comments, creating let and const variables and printing them to the console.

Main ideas:
1. The page is a minimal valid HTML5 document with English language, a UTF-8 charset, a viewport meta tag, and the title "Task 09a - Variables Practice."
2. The visible body has an h1 heading, "Task 09a: JavaScript Variables Practice," and one paragraph telling you to complete the code and check the console (F12) to verify your work.
3. Below that is a script element that contains only comments. Each TODO comment is followed by blank lines where you type your code. Nothing runs until you add code.
4. The task practices the difference between let (can change) and const (fixed), the string, number, and boolean data types, and printing with console.log().

Key terms:
let — declares a variable that can be reassigned later.
const — declares a variable that cannot be reassigned.
string — text in quotes.
number — a numeric value with no quotes.
boolean — true or false.
console.log() — prints a value to the browser console.
TODO comment — an instruction comment marking code you must write.
template literal — a backtick string that inserts values; used in the bonus.

What you are asked to do:
The TODO comments inside the script, in order:
1. Create a string variable for your name, using let, with any name you want.
2. Create a number variable for your age, using let.
3. Create a boolean variable showing whether you are a student, using let, set to true or false.
4. Create a const variable for your school name, since your school does not change.
5. Create a const variable for the current course code, set to 'WEB101'.
6. Print all your variables with console.log(), using at least 5 console.log statements.
7. Create a second string variable for your favorite color, using let.
8. Print the color variable to the console.
9. Create a number variable for your favorite number, using let.
10. Print the favorite number to the console.
11. Try to reassign the const you created. A commented-out line, schoolName = 'Different School'; is provided; uncomment it to see the error. The comment says the error is expected; that is what is being tested.
12. Bonus: build a template literal that combines your name and age and print it, for example "My name is Alex and I am 16 years old."

Watch out for:
- The provided reassignment line uses the name schoolName, so your school const must be named schoolName for that test to hit your variable.
- Once you uncomment that line, the error stops the script at that point, so any code after it will not run. Comment it back out after you see the error.
- If the console is blocked on school computers, the Unit Guide's say() output-div method puts the output on the page instead.
