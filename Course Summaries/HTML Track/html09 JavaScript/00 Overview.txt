Overview of: html09 JavaScript
Course: HTML CSS JavaScript track

What this lesson is about:
This is the course's JavaScript unit, created by merging two older lessons, html09 JavaScript Basics and html10 JS DOM and Interactivity. That is why some files still say "Lesson 10" or "HTML10." It runs about 5 to 6 class periods in three sub-units. The first sub-unit, core JavaScript (09a and 09b), covers the script tag, the console, variables with let and const, data types, functions with parameters and return, string concatenation, and comments, and ends with a Mad Libs story project. The second sub-unit, the DOM (09c), teaches how JavaScript selects page elements, changes their text and styles, listens for events like clicks, and shows or hides things with classList. The third sub-unit, Feature Days (09d to 09f), applies one move, select, listen, toggle a class, and let CSS finish, to add a dark mode toggle and an accessible hamburger menu to your real website, then adds form validation to your html08 form. You leave able to read and direct simple JavaScript, explain why hover belongs to CSS, keep aria-expanded in sync on toggle buttons, and explain why a server must re-check form data. The unit covers ODE competencies 6.3.1, 6.3.2, 6.3.3, and 6.4.7.

How the pieces fit together:
- The Unit Guide is the current master plan and says to start there. It maps each segment to its files: 09a to 09b basics, 09c DOM core, 09d dark mode day, 09e hamburger day, and 09f form validation plus the server discussion.
- The README and MANIFEST describe only the original basics package (the Mad Libs half). They list solution files and quiz CSV files that are not in this folder. Read them as background.
- Two graded projects: the Mad Libs DIY task closes the basics half, and the Features DIY task is the capstone for the whole unit. The Extension Task is optional extra credit.
- The Unit Guide warns that the F12 console may be blocked on school computers; if so, use its say() output-div method wherever lessons say console.log().

Other files in the original lesson:

The README and MANIFEST list files that are not present: walkthrough solutions, Task 09a and 09b solutions, Mad Libs solutions (each in .html and .js form), and two quiz files (html09_Gimkit.csv and html09_GoogleQuiz.csv, 30 questions each). The Unit Guide also names a teacher solution for the Features DIY task in a teacher folder. These appear to be teacher-only files.

Things to know about conflicts in the sources:
- Hover effects belong in CSS (:hover). The newer Unit Guide retires the JavaScript hover exercise, so follow it even though the DOM slides and the html09d Task still show JavaScript hover.
- Concatenation with the plus sign is the tested form, per the Unit Guide; template literals are shown once. The older basics files lean on template literals, and the Mad Libs project still requires one, so know both.
- The DOM walkthrough has no validation section, even though the Unit Guide points 09f there; study validation from the DOM slides, DOM study guide, and html09d Task.
