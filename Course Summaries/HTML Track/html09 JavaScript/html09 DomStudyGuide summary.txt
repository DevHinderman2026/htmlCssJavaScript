In one sentence:
This study guide for the DOM half of the unit (still titled "HTML10 Study Guide: JS DOM and Interactivity") gives vocabulary, a code cheat sheet, competencies, objectives, and common mistakes (its 7 practice questions are left out of these study notes).

Main ideas:
1. Vocabulary is grouped in four areas: DOM and selecting, changing content and style, events, and form validation. All terms appear under Key terms below.
2. Cheat sheet, selecting. By id with document.getElementById('myId'); by selector with document.querySelector('.myClass') for the first match; and document.querySelectorAll('p') for every paragraph.
3. Cheat sheet, content. innerHTML set to '<strong>New HTML</strong>' puts bold HTML inside; textContent set to 'Just text' puts plain text inside.
4. Cheat sheet, styles. element.style.color = 'red'; element.style.backgroundColor = 'yellow'; element.style.display = 'none' hides; element.style.display = 'block' shows.
5. Cheat sheet, event listeners. A click listener logs "Element was clicked"; a mouseover listener logs "Mouse is over element"; and a submit listener receives an event object and calls event.preventDefault() so the form does not actually submit, leaving room to validate.
Code: element.addEventListener('submit', function(event) { event.preventDefault(); });
In words: when the form is submitted, run this function, and the first thing it does is stop the browser's normal submit behavior.
6. Cheat sheet, classes. classList.add('active') adds a class, classList.remove('hidden') removes one, and classList.toggle('open') flips one on or off.
7. Cheat sheet, simple validation. Read the email input's value. If it is exactly an empty string, show an error and return false. If it does not include the at sign, it is not a valid email, so return false.
8. ODE competencies listed: 6.2.7 (develop pages using hover and mouseover effects), 6.4.7 (use scripting to interact with data and forms), and 6.3.1 (use scripting languages to develop pages).
9. Learning objectives. By the end, students can: select elements with JavaScript; change content and styles; respond to events with listeners; validate form input before submitting; explain why hover effects belong to CSS using :hover and not JavaScript; and build interactive elements such as a dark mode toggle and a mobile nav, with accordions as an extension task.

Key terms:
DOM (Document Object Model) — a tree structure representing the HTML page, used by JavaScript to access and change elements.
document — the global JavaScript object that gives access to the whole page.
getElementById() — selects an element by its id attribute; the fastest method.
querySelector() — selects the first element matching a CSS selector.
querySelectorAll() — selects all elements matching a CSS selector and returns a list.
innerHTML — reads or writes the HTML inside an element, including tags.
textContent — reads or writes only the plain text inside an element, no tags.
style property — the JavaScript object controlling an element's inline CSS.
event — something that happens on a page, such as a click, hover, typing, or submit.
event listener — code that waits for an event and runs a function when it happens.
addEventListener() — the method that attaches an event listener to an element.
click event — fires when the user clicks an element.
mouseover — fires when the mouse enters an element.
mouseout — fires when the mouse leaves an element.
submit event — fires when a form is submitted.
preventDefault() — stops an event's default behavior, such as a form actually submitting.
form validation — checking that input is valid before processing it.
classList — manages an element's CSS classes without replacing its other classes.
add() — classList method that adds a class.
remove() — classList method that removes a class.
toggle() — classList method that adds a class if absent or removes it if present.

Watch out for:
Common mistakes the guide lists:
- Forgetting quotes around the id or selector string: getElementById("id"), not getElementById(id) with no quotes.
- Using a single equals sign (assignment) instead of triple equals (comparison): write value === '' not value = ''.
- Trying to reach elements before the page has loaded, which gives you nothing to work with.
- Forgetting event.preventDefault() when you need to stop default behavior, such as a form reloading the page.
- Using inline event handlers instead of addEventListener().
- Confusing innerHTML, which turns text into HTML, with textContent, which does not.
Correction: competency 6.2.7 (hover effects) is a CSS skill, done with the :hover pseudo-class, as the guide's own objectives and the Unit Guide say; the guide's competency list wording "hover and mouseover effects" is older. Expect hover questions to be about CSS :hover.
