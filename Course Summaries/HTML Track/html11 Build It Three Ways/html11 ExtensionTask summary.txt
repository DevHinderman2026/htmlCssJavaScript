In one sentence:
This optional fast-finisher task, "The Fourth Build," adds one more build to your comparison matrix.

Main ideas:
1. It is for fast finishers only and is extra credit with no points and no rubric. You must finish segments 11a through 11g first.
2. You add one more column to your comparison matrix, choosing one of two options.
3. Option 1, another builder: use Wix or Canva Sites (both have free tiers). Rebuild the two-page version of your site, run the same usability checklist, and add the column.
4. Option 2, a second AI: give a different AI tool the same spec, then compare the two AI builds. Because the same components were requested, the point is to see how much the code quality differs. Write five findings comparing the two AI builds with each other.

Key terms:
Extension task — optional extra work beyond the required project.
Diff — to compare two versions side by side and note the differences.

What you are asked to do:
- Choose option 1 (Wix or Canva Sites) or option 2 (a second AI tool).
- For option 1: rebuild the two-page version, run the usability checklist, add the column.
- For option 2: same spec to a different AI, then five findings comparing the two AI builds.
- Commit an updated html11_Comparison_lastname.md with the new column plus a paragraph on whether it changed your verdict.

Watch out for:
- Do not start this until all of 11a through 11g is done.
