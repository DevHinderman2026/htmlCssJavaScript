In one sentence:
This guide explains segment 11c, where you direct an AI to build your client's site using named Bootstrap components, then critique the generated code in writing and send it back for one round of fixes.

Main ideas:
1. The core rule: you are the director, not a spectator. A vague request like "make me a website for a diner" produces generic junk. Your job is to specify exactly what you want using the vocabulary you learned all semester plus the Bootstrap component names.
2. Step 1, know the component menu. Skim the Bootstrap study guide in the enrichment Bootstrap Basics folder. You are not learning to write Bootstrap; you are learning to name its parts. The components listed are: navbar, hero or jumbotron, card grid, carousel, badge, alert, accordion, footer columns, and breadcrumb. These names are how professionals talk about the "furniture" of a page.
3. Step 2, direct the build. Your spec to the AI must name at least:
- the client and audience (reuse your proposal);
- the pages and their navigation structure;
- which Bootstrap components go where, for example a navbar that collapses on mobile, a hero with the diner's name, a 3-column card grid for menu categories, and a carousel of historical photos;
- content requirements: your table, your form, and real headings;
- non-negotiables: semantic HTML5 elements, alt text on every image, and external CSS.
Save the full conversation or a prompt log, because it is graded.
4. Step 3, the critique, which is the graded heart of the segment. Read the generated code and write at least five specific findings. The classic problems to hunt for are: div soup where semantic elements belong; missing or useless alt text (such as "image.png"); inline styles that belong in the stylesheet; fake headings (styled text instead of real heading tags); form inputs without labels; and heading levels that skip.
5. If the AI's code is truly clean in some area, say so and prove it. A "no problem here" claim needs evidence too.
6. Step 4, one revision round. Send your top three findings back to the AI as instructions to fix them, then verify whether it really fixed them, and note in the critique which fixes worked.

Key terms:
Prompt log — a saved record of everything you told the AI and its replies.
Spec — the detailed description of what you want built.
Jumbotron or hero — a large banner section at the top of a page.
Carousel — a slideshow component that cycles through images or items.
Badge — a small label, such as a count or "New" tag.
Accordion — a stack of sections that expand and collapse.
Breadcrumb — a trail of links showing where you are in the site, such as Home, then Menu, then Desserts.
Inline style — CSS written in an element's style attribute instead of in the stylesheet.

What you are asked to do:
- Write a spec for the AI covering all five required items above.
- Save the full conversation or a prompt log.
- Write html11_AICritique_lastname.md (with your last name) containing at least five specific findings. Each finding needs: the line or section, what is wrong or questionable, and what you would change.
- Send your top three findings back to the AI as fix instructions, check the results, and record which fixes worked in the critique.
- Commit the AI-built site in its own folder, the prompt log, and the critique file.

Watch out for:
- Vague prompts produce generic results; name components and requirements.
- Do not trust that the AI fixed something; verify it in the code.
- Screen-reader tip for reviewing: check for labels on every input, real h1 to h6 headings in order, and meaningful alt text; these are exactly the problems on the hunt list.
Correction: jumbotron was removed in Bootstrap 5, so ask the AI for a hero section (a section or div styled with utility classes), not a jumbotron. The Bootstrap Basics study guide covers only the navbar, cards, buttons, alerts and forms, so look up carousel, badge, accordion and breadcrumb in the official Bootstrap 5 documentation at getbootstrap.com.
