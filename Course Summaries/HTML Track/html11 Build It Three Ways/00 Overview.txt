Overview of: html11 Build It Three Ways
Course: HTML CSS JavaScript track

What this lesson is about:
Build It Three Ways is the course's culminating project and replaces the old capstone. You pick one client (a soccer league, a diner, a makers club, an animal rescue, or an approved organization of your own) and build a website for them three ways: by hand-coding your polished semester site with dark mode and mobile nav, by directing an AI using named Bootstrap components, and with no-code builders (Google Sites and WordPress.com). You also spend a media day optimizing images and making an SVG logo. Then you test all the builds with the same usability checklist, compare them in a matrix, and write a verdict on which one your client should really use. The most heavily graded part is your written critique of the AI's code, finding problems like div soup, missing alt text, fake headings, and unlabeled inputs. You finish with a handoff document for the client and a 5-minute presentation. You leave with planning, evaluation, and professional judgment skills, not just coding skills.

None. The source folder has only these ten Markdown files. Segment 11b (the hand-coded build) has no document of its own; it uses your existing semester repository. The rubric and worked exemplars mentioned in the Unit Guide are in a teacher folder that is not included.
